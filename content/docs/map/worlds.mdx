## 从一个世界和一个锚点开始

文件名必须对应实际世界。若测试世界为 `world`，在 `plugins/ArcartX-Suite/data/map/worlds/world.yml` 合并下例，并把锚点坐标换成玩家能够站立的安全落点。其他世界使用其真实名称建文件。

```yaml
enabled: true
display-name: "生存世界"
anchors:
  trial_spawn:
    enabled: true
    display-name: "试炼出生点"
    x: 0
    y: 80
    z: 0
    permission: ""
    unlock:
      default: true
```

管理员执行 `/axs reload map` 后，用 `/axs map anchors world` 确认 `trial_spawn` 已加载。普通玩家使用 `/map open world`，在左下角「☰」展开锚点列表并选择「试炼出生点」。确认免费解锁后可传送，实际落点与配置一致。最后在已探索区域确认地形出现。列表正常但地形空白时，先核对 Map 客户端扩展，再检查预加载范围和世界对应关系。

默认解锁只控制拥有状态，锚点另有 `permission` 时仍需持有权限。做付费解锁时先把默认解锁关闭，再逐项加入货币、物品和条件。移动锚点后重新检查落点，避免玩家传送到空气或方块内部。

已有地图地形发生大范围修改时，用 `/axs map refresh <世界ID>` 更新地形版本。先小范围验证，再扩大预加载范围。

## 概述

每个世界单独配置显示名称、锚点、预加载范围和点亮条件。玩家安装 [ArcartX-Suite-Map](./client-mod) 后可查看地图地形。

### 目录结构

每个世界一个独立文件，放在 `data/map/worlds/` 目录下（目录名由 `worlds-directory` 配置，默认 `worlds`），**文件名即世界 ID**（对应 Bukkit world name，大小写不敏感）：

```
data/map/
  config.yml
  worlds/
    world.yml            ← 世界 ID = world
    bskyblock_world.yml  ← 世界 ID = bskyblock_world
```

模块启动时按文件名字母顺序加载目录下所有 `.yml` 文件。目录不存在时自动创建并导出示例文件 `worlds/world.yml`。

### 字段说明

```yaml
# worlds/world.yml — 文件名即世界 ID
enabled: true
display-name: ""

anchors:
  spawn:
    enabled: true
    display-name: "出生点"
    x: 0
    y: 64
    z: 0
    description: "默认出生点锚点。"
    permission: ""
    sort-order: 0
    unlock:
      default: true
      on-permission: false
      currencies: []
      items: []
    teleport:
      currencies: []
      items: []
    light:
      radius: 100
```

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `enabled` | `boolean` | `true` | 是否在地图菜单中显示此世界 |
| `display-name` | `String` | `""` | 显示名称；留空时运行时从 Multiverse-Core colourless alias 自动补 |
| `anchors` | `Map` | — | 该世界的锚点列表（见 [锚点系统](./anchors)） |

<Callout type="info">
世界维度自动识别，无需手动填写。缩放与视野由玩家在客户端用鼠标滚轮和拖拽调整。
</Callout>

### 世界选择逻辑

当玩家打开地图或 HUD 时，按以下优先级确定初始世界：

1. 玩家请求指定的世界 ID（已配置时使用）
2. 玩家在地图中已选中的世界
3. 玩家当前所在的世界（已配置时）
4. 配置中的第一个世界

> 均不满足时，地图菜单提示「当前世界未配置地图，且没有可用的默认地图」，HUD 提示「当前没有可显示的小地图世界」。

## 显示玩家未探索的区域

玩家可以留在别的世界，通过大地图查看指定区域。目标世界须在服务器上加载，所选范围内的区块须已生成。地图预加载只读取已有地形。首次配置时可先选一块已经建好的出生区，把地图范围控制在几十格内。

Paper 等支持异步区块加载的服务端可以预加载已生成但暂未加载的地形。仅能同步加载区块的服务端，地图预加载使用当前已加载的区块。

暂时未读到区块时会先显示已取得的地形。世界预加载由客户端补拉，仅请求仍缺失的区块。跨服浏览的地形也会分批显示。

### 打开地图就显示出生区

在 `plugins/ArcartX-Suite/data/map/worlds/world.yml` 的现有 `preload` 小节填入下例。把文件名和中心坐标换成实际世界及出生区位置。

```yaml
preload:
  center:
    x: 100
    z: -200
  radius: 64
  regions: []
```

| 字段 | 填写方法 |
| --- | --- |
| `preload.center` | 圆形区域的世界 X、Z 坐标，留空时取世界出生点 |
| `preload.radius` | 半径，单位为方块，设为 `0` 时关闭圆形预加载 |
| `preload.regions` | 多边形列表，每项填写 `points`，至少三个 X、Z 顶点。可与圆形区域叠加 |

执行 `/axs reload map` 后，让未进入过目标世界的测试玩家在其他世界运行 `/map open world`。玩家安装地图 Mod 后，等待地形加载，确认能看见示例范围内已生成的地形。启用点亮的世界中，预加载范围也计入可见区域，因此适合向所有浏览该世界的玩家展示。

### 解锁锚点后才显示目标区

把目标区配置在锚点的 `light` 下，并将该区域留在世界预加载范围之外。下面的锚点以 X=300、Z=-200 为中心点亮 48 格。示例允许玩家远程手动解锁，使用前将 Y 改为实际可站立的高度。

```yaml
anchors:
  trial_outpost:
    enabled: true
    display-name: "试炼前哨"
    x: 300
    y: 80
    z: -200
    permission: ""
    unlock:
      default: false
      on-permission: false
      radius: 0
    light:
      radius: 48
```

用尚未解锁该锚点的玩家打开目标世界，确认前哨区域仍被遮罩。选中锚点后点击「解锁」，等待成功提示和地形加载，再确认前哨区域显示。让该玩家重登并打开同一世界，核对已加载的地形仍然可见，暂缺的区块会继续加载。换设备后，已解锁的玩家也可从服务器加载该点亮范围。

## 点亮区域（战争迷雾）

玩家解锁配置了点亮范围的锚点后，可在大地图上查看对应区域。重登并打开对应世界时，客户端先读取本机地形缓存，再补拉缺失区块。服务端按玩家的解锁状态和锚点权限校验补拉请求。

大地图加载选中世界的点亮区域，小地图加载玩家当前世界的点亮区域。

每个锚点支持两种写法（可同时配置，任一生效即可）：

| 字段 | 格式 | 说明 |
|---|---|---|
| `light.region.points` | `[[x,z], ...]` | 多边形顶点列表（至少 3 点），世界坐标 |
| `light.radius` | 数值 | 以锚点为中心的圆形点亮半径（方块数） |

```yaml
anchors:
  spawn:
    # ...
    light:
      region:
        points: [[-50, -50], [50, -50], [50, 50], [-50, 50]]
      radius: 100
```

启用点亮后，玩家可以看到所有已解锁锚点覆盖的区域。省略锚点的 `light` 小节时，该锚点不会增加点亮范围。

## 检查地形显示

| 看到的现象 | 检查方法 |
| --- | --- |
| 锚点已显示，周围没有地形 | 核对客户端 Mod、世界名和目标世界是否已加载，再确认预加载或点亮范围内有已生成区块 |
| 部分地形一直空白 | 确认目标区块已生成。仅能同步加载区块的服务端还须确认区块已加载。锚点点亮区域还需核对 `light` 的范围、玩家权限和解锁状态 |
| 区域提示尚未点亮 | 检查玩家是否已解锁覆盖该位置的锚点，并核对圆心、半径或多边形顶点 |
| 解锁前就能看到该区域 | 检查预加载范围及其他已解锁锚点是否与目标区域重叠 |
| 改建后预加载或锚点点亮区域仍显示旧地形 | 刷新该世界的地形，例如执行 `/axs map refresh world` |

缩放、拖动及地图状态提示见[客户端 Mod](./client-mod)。

## 多世界切换

玩家在地图菜单点击世界列表项即可切换世界视图，标点选中状态自动清除。世界列表按 `worlds/` 目录文件名字母序排列，每项显示世界名称和选中状态。
