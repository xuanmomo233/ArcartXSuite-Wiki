Regions 为世界和长方体区域设置建造、交互、战斗、传送、拾取及聊天规则。管理员在面板中点「允许」「禁止」即可保存，区域范围、成员和规则都能在 `regions.yml` 查阅。

| 项目 | 位置或用法 |
| --- | --- |
| 模块 ID | `regions` |
| 通用配置 | `plugins/ArcartX-Suite/data/regions/config.yml` |
| 区域与世界规则 | `plugins/ArcartX-Suite/data/regions/regions.yml` |
| 消息 | `plugins/ArcartX-Suite/data/regions/messages.yml` |
| 管理面板 | `/rg admin` |
| 玩家菜单 | `/rg menu` |
| 手动修改后的重载 | `/axs reload regions` |

## 第一次使用

下面以管理员建立出生点为例，需要 `axs.regions.select` 和 `axs.regions.admin`。

1. 执行 `/rg wand` 获取木斧，在出生点的两个对角方块左键、右键设点。选区包含高度，应覆盖玩家能够活动的楼层。
2. 执行 `/rg preview` 检查范围，然后执行 `/rg define spawn spawn`，用内置出生点模板创建管理区域。
3. 打开 `/rg admin`，在「区域」中选中 `spawn`。在「规则开关」选择类别，设置允许或禁止，点击「继承」清除这一项覆盖。
4. 等待界面显示「已保存」，再查看模块目录中的 `regions.yml`。在线修改会在文件保存成功后生效。

普通玩家创建领地可用 `/rg define home claim`，其中第二个 `claim` 是内置模板名称。区域类型取决于创建者权限，有管理员权限的账号创建 `managed`，普通账号创建 `claim`。

## 世界默认与局部区域

| 类型 | 用途 | 管理方式 |
| --- | --- | --- |
| `managed` | 出生点、城镇、竞技场等管理区域 | 管理员修改 |
| `claim` | 玩家自己的领地 | 所有者管理成员和可编辑规则 |
| `global` | 某世界的默认规则，默认 ID 为 `__global__` | 管理员在「世界」中编辑 |

管理区域优先于玩家领地。同类区域按优先级判断，同级冲突时禁止优先。区域未设置的规则可继承父区，未取得局部结果时使用世界默认值。 [标志系统](/docs/regions/flags)

## 检查是否配置成功

使用没有绕过权限、也不是规则来源区域成员的测试账号，在出生点内外尝试破坏方块。区域内应按出生点规则处理。

在 `/rg menu` 的「当前位置」查看生效规则和来源。管理员可用 `/rg why block-break Alex` 查询 Alex 所在位置的破坏判定。

需要核对一块区域的直接配置时，在管理面板选中该区域，或使用 `/rg flags world:spawn`。方块交互、拾取和传送还会检查实际目标位置，具体范围见[世界规则](/docs/regions/world-rules)。
