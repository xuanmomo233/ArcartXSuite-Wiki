Regions 的模块目录是 `plugins/ArcartX-Suite/data/regions/`。手动修改文件后执行 `/axs reload regions`。通过命令或管理面板保存时，文件写入成功后会更新保护规则。

| 文件 | 内容 |
| --- | --- |
| `config.yml` | 选区限制、区域初始值、模板和通知方式 |
| `regions.yml` | 每个区域与世界的范围、优先级、父区、成员、旗标及操作记录 |
| `messages.yml` | 命令和保护提示文字 |
| `plugins/ArcartX-Suite/ui/regions_control.yml` | 管理面板的界面文件 |
| `plugins/ArcartX-Suite/ui/regions_view.yml` | 玩家菜单的界面文件 |

`regions.yml` 在第一次保存时生成，也可以按下文示例创建。区域和世界规则直接保存在此文件中。每台服务器读取自己的模块目录，规则文件可按服务器需要分别配置。

## 通用设置

下面示例可作为 `config.yml` 的基础内容，模板可在其后继续添加。

```yaml
config-version: 4
debug: false

selection:
  # 选区工具
  wand-item: WOODEN_AXE
  # 两个角点组成的体积上限
  max-volume: 500000
  # 普通玩家创建领地时的数量上限，0 取消数量上限
  max-regions-per-player: 20

defaults:
  priority: 0
  global-region-id: "__global__"

notifications:
  show-actionbar: true
  display-mode: actionbar
```

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `config-version` | `4` | 通用配置版本，使用模块生成的值 |
| `debug` | `false` | 模块调试开关 |
| `selection.wand-item` | `WOODEN_AXE` | Bukkit 选区工具物品名称 |
| `selection.max-volume` | `500000` | 每次通过选区创建或更新区域的体积上限，配置诊断范围为 1～100000000 |
| `selection.max-regions-per-player` | `20` | 普通玩家领地数量限制，`0` 取消限制，`axs.regions.bypass.limit` 可绕过此项 |
| `defaults.priority` | `0` | 新建有界区域的初始优先级 |
| `defaults.global-region-id` | `__global__` | 每个世界默认记录使用的 ID，与 `type: global` 的记录保持一致 |
| `notifications.show-actionbar` | `true` | 没有自定义进出文字时，是否显示默认进出提示 |
| `notifications.display-mode` | `actionbar` | 进出提示位置，可用 `actionbar`、`chat`、`title` |

`display-mode` 同时用于默认提示和自定义的 `greeting`、`farewell`。关闭 `show-actionbar` 后，显式配置的自定义文字仍按选择的位置显示。

## 区域与世界数据

`regions.yml` 的 `version: 2` 描述区域数据格式。`regions` 是区域记录列表，同一世界的区域 ID 必须唯一。

下面示例为世界设置禁飞和禁活塞，为城镇设置建造保护并允许飞行，再定义一块由权限组管理的玩家领地。

```yaml
version: 2
regions:
  - id: __global__
    world: world
    type: global
    flags:
      fly: false
      pistons: false
    blocked-interactions:
      - ANVIL

  - id: town
    world: world
    type: managed
    min: [0, 60, 0]
    max: [49, 100, 49]
    priority: 10
    flags:
      fly: true
      block-break: false
      block-place: false
      chest-access: false
      greeting:
        state: true
        text: "&6欢迎来到城镇！"

  - id: home
    world: world
    type: claim
    min: [200, 60, 200]
    max: [219, 85, 219]
    owner-groups: [home_owners]
    member-groups: [home_members]
    flags:
      block-break: false
      block-place: false
      use: false
      chest-access: false
```

此领地示例的所有者组对应权限 `axs.regions.group.home_owners`，成员组对应 `axs.regions.group.home_members`。直接按玩家管理时，使用面板或 `/rg addowner`、`/rg addmember`，模块会将对应 UUID 写入记录。

### 记录字段

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| `id` | 是 | 区域名称，1～64 位文字、数字、下划线或连字符，同世界内不区分大小写 |
| `world` | 是 | 世界文件夹名称，按实际大小写填写 |
| `type` | 是 | `managed` 管理区域、`claim` 玩家领地、`global` 世界默认 |
| `min`、`max` | 有界区域必填 | 三个整数 `[X, Y, Z]`，每个方向最小坐标不大于最大坐标，边界包含在保护范围内 |
| `priority` | 否 | 整数，默认 `0`，用于同类区域的优先级比较 |
| `parent` | 否 | 同一世界的父区域 ID，省略代表没有显式父区 |
| `uuid` | 否 | 区域稳定标识，新记录可省略；已有记录重命名、重定义时保留 |
| `owners`、`members` | 否 | 所有者或成员的 UUID 字符串列表 |
| `owner-groups`、`member-groups` | 否 | 所有者或成员权限组名称列表 |
| `flags` | 否 | 直接设置的旗标映射，省略的旗标进入继承或世界默认判定 |
| `blocked-interactions` | 否 | 世界默认记录专用，按 Bukkit 方块材质名列出禁交互对象 |

每个世界最多一条 `global`，它的 ID 使用 `defaults.global-region-id`，并省略坐标和父区。玩家领地需要至少一个所有者 UUID 或所有者权限组。父区类型限制见[父区域与世界默认值](/docs/regions/flags#父区域与世界默认值)。

### 布尔规则与文本

`regions.yml` 中的普通旗标必须填写 YAML 布尔值，允许为 `true`，禁止为 `false`。省略旗标时，使用继承或默认判定。

```yaml
flags:
  pvp: false
  use: true
  greeting:
    state: true
    text: "&a欢迎来到集市！"
```

只有 `greeting` 和 `farewell` 可填写 `state` 与 `text` 对象，文字最多 1024 个字符。所有可用键见[旗标参考](/docs/regions/flags#旗标参考)。

### 保存与重载

面板修改后的「已保存」表示该次修改已写入文件。显示保存失败时，按提示处理后重新保存，再用玩家菜单检查结果。

手动编辑文件后执行 `/axs reload regions`，再打开管理面板。面板提示“regions.yml 已被手动修改”时，也按此步骤重新加载。

需要查看或撤销一次设置时，使用 `/rg history`、`/rg diff` 和 `/rg undo`，操作步骤见[撤销一次设置](/docs/regions/management#撤销一次设置)。

## 区域模板

模板填写在 `config.yml` 的 `templates` 下，名称使用 1～64 位小写英文字母、数字、下划线或连字符。模板状态使用 `allow`、`deny`、`none`。应用时仅更新列出的旗标，`none` 清除对应覆盖。

```yaml
templates:
  market:
    block-break: deny
    block-place: deny
    use: allow
    chest-access: deny
    greeting:
      state: allow
      text: "&6欢迎来到市场！"
```

重载后可用以下命令检查和应用。

```text
/rg template show market
/rg template apply market world:town
```

内置 `spawn`、`public`、`claim`、`arena` 模板的用途见[用模板创建或更新区域](/docs/regions/management#用模板创建或更新区域)。普通领地所有者只能使用全部旗标均允许其编辑的模板。

## 消息文字

`messages.yml` 支持 `&` 颜色代码。保留实际文件的其他键，修改需要调整的文字即可。

```yaml
region-created: "&a区域 &f{name} &a已创建。"
no-build: "&c你不能在此区域放置或破坏方块。"
no-interact: "&c你不能在此区域操作这个对象。"
region-enter: "&a[进入] &f{region}"
region-leave: "&a[离开] &f{region}"
```

| 消息键 | 占位符 | 用途 |
| --- | --- | --- |
| `wand-pos1`、`wand-pos2` | `{x}`、`{y}`、`{z}` | 选点成功提示 |
| `region-created`、`region-deleted`、`region-not-found` | `{name}` | 创建、删除和查询提示 |
| `flag-set` | `{region}`、`{flag}`、`{value}` | 旗标保存提示 |
| `member-added` | `{player}`、`{region}`、`{role}` | 成员添加提示 |
| `member-removed` | `{player}`、`{region}` | 成员移除提示 |
| `region-enter`、`region-leave` | `{region}` | 默认进出文字 |
