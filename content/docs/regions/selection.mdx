Regions 的选区由同一世界的两个方块角点组成，X、Y、Z 三个方向都包含边界。例如 `[0, 60, 0]` 到 `[9, 69, 9]` 的体积为 1000 方块。

## 设置两个角点

执行 `/rg wand` 获取选区工具，默认是木斧，需要 `axs.regions.select`。

| 操作 | 选点位置 |
| --- | --- |
| 手持工具左键方块 | 角点一使用点击方块的坐标 |
| 手持工具右键方块 | 角点二使用点击方块的坐标 |
| `/rg pos1` | 角点一使用玩家站位的方块坐标 |
| `/rg pos2` | 角点二使用玩家站位的方块坐标 |

两个点可以从任意对角方向选择，创建时会归一化最小值和最大值。重新设置角点一到其他世界会清除角点二，角点二跨世界时会提示重新选择。退出游戏会清除选区。

在 `/rg menu` 的「我的选区」中可核对世界、两个角点和体积，也可刷新或清除选区。

## 创建与检查

```text
/rg pos1
/rg pos2
/rg preview
/rg define spawn spawn
/rg info world:spawn
```

执行两个设点命令前，分别站到要使用的两个角点。`preview` 显示体积和重叠区域，`define` 的最后一个参数是模板名称。

选区应覆盖需要保护的完整高度。区域名称、世界和范围可在 `regions.yml` 中查看，字段说明见[配置文件](/docs/regions/configuration#区域与世界数据)。

普通玩家领地创建或重定义时会检查重叠，遇到冲突需调整选区。管理员可建立重叠的管理区域，按旗标优先级提供局部规则。创建和重定义成功后，相应选区会清除。

## 修改已有区域

1. 重新设置同一世界的两个角点。
2. 使用 `/rg preview world:spawn` 检查冲突，该次预检会排除 `spawn` 本身。
3. 使用 `/rg redefine world:spawn` 保存边界，或在管理面板的「区域设置」中选择「采用当前选区」。
4. 使用 `/rg info world:spawn` 核对结果。

重命名使用 `/rg rename world:spawn town_spawn`，或在「区域设置」保存新名称。区域 UUID 保持不变，子区域的父区引用会随名称更新。

## 选区限制

以下字段填写在模块的 `config.yml` 中。

```yaml
selection:
  wand-item: WOODEN_AXE
  max-volume: 500000
  max-regions-per-player: 20
```

| 字段 | 作用 |
| --- | --- |
| `wand-item` | 选区工具的 Bukkit 物品名称 |
| `max-volume` | 每次使用选区创建或更新区域的体积上限，默认 500000 |
| `max-regions-per-player` | 普通玩家创建领地时的数量上限，默认 20，填 0 取消数量上限 |

`axs.regions.bypass.limit` 可绕过普通玩家的数量限制。最大体积仍按 `max-volume` 检查。

## 粒子与附近边框

| 显示 | 颜色 | 用途 |
| --- | --- | --- |
| 角点一 | 红色 | 标记第一个方块角点 |
| 角点二 | 绿色 | 标记第二个方块角点 |
| 选区边框 | 青色 | 勾勒选区的十二条棱 |
| 已建区域边框 | 黄色 | 普通玩家预览自己拥有或参与的区域 |
| 已建区域边框 | 紫色 | 管理员预览附近区域 |

执行 `/rg show` 开启或关闭已建区域边框。每 16 tick 查询玩家附近 48 方块内的区域，远处边线会裁剪。每人每轮最多 400 个区域边框粒子，全服每轮最多 1600 个，多个查看者轮流显示。

当前选区每 8 tick 更新一次，选区边线每轮最多 600 个粒子。粒子发送给查看者本人。

## 传送到区域

`/rg tp world:spawn` 在区域 X、Z 中心列，从区域允许的最高 Y 向下寻找落点。脚下需要有实心方块，脚部和头部需要有空气，岩浆块会被排除。找不到满足条件的位置时会提示调整目标范围。

目标世界需要已加载，传送也会经过 `teleport`、`entry`、`exit` 等规则检查。相关设置见[世界规则](/docs/regions/world-rules)。
