| 项目 | 说明 |
| --- | --- |
| 模块 ID | `tooltip` |
| 主配置 | `plugins/ArcartX-Suite/data/tooltip/config.yml` |
| 主要调整内容 | 提示展示开关与枪械界面模式 |
| 重载 | `/axs reload tooltip` |

## 开始前

用 `/axs status` 确认模块已加载，再用 ArcartX 客户端检查界面。

## 第一次使用

按[客户端安装与验证](/docs/tooltip/client-mod#安装后验证)安装作者发放的扩展。测试枪械浏览时，用已安装 TACZ 的客户端悬停在有适用枪械的配件上。

## 检查是否配置成功

按下并松开「查看支持枪械」键，应看到该配件的枪械列表。只验证物品说明时，用已配置的[提示样式](/docs/tooltip/tip-example)核对显示内容。

TACZ 配件未显示枪械列表时，检查客户端是否加载 Tooltips。按下「查看支持枪械」键后松开，用 `/axs tooltip status` 核对 `gun-list.mode`。

## 可以配置的功能

| 特性 | 说明 |
|---|---|
| 客户端 tooltip 采集 | 客户端 ArcartX-Suite-Tooltips 采集 tooltip 文本行和结构化数据并发送给服务端 |
| 结构化数据 | 客户端可报告 TaCZ 枪属性等数据，用于该玩家自己的展示。实际属性和公开物品预览以服务端数据为准。 |
| 自动清理 | 缓存 60 秒自动过期，玩家退出时立即清理其全部缓存数据 |
| 管理命令 | `/axs tooltip status`（缓存/模式/通道）+ `/axs tooltip push <玩家>`（手动重推模式） |
