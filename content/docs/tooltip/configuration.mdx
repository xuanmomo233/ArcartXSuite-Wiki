---
title: "物品提示配置"
description: "选择枪械浏览界面并配置物品提示与命令文本。"
---

在 `plugins/ArcartX-Suite/data/tooltip/` 编辑界面设置 `config.yml` 或命令文本 `messages.yml`，然后执行 `/axs reload tooltip`。玩家须安装[客户端扩展](/docs/tooltip/client-mod)。界面写法见[物品提示示例](/docs/tooltip/tip-example)。

## 主配置文件（`config.yml`）

```yaml
gun-list:
  mode: ax
```

| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `gun-list.mode` | string | `ax` | `ax` 使用 ArcartX 界面，`mod` 使用客户端模组界面 |

## 消息文件（`messages.yml`）

`messages.yml` 首次启动时自动释放到 `plugins/ArcartX-Suite/data/tooltip/messages.yml`，定义管理命令输出的所有文本。

### 消息键一览

| 消息键 | 说明 | 参数 |
|---|---|---|
| `prefix` | 所有消息的前缀 | 无 |
| `common.no-permission` | 无权限提示 | 无 |
| `common.player-only` | 仅玩家可执行提示 | 无 |
| `admin.status-title` | 状态命令标题 | 无 |
| `admin.status-cache-size` | 缓存玩家数 | `{0}` - 玩家数量 |
| `admin.status-ttl` | 缓存 TTL | `{0}` - TTL 秒数 |
| `admin.status-no-cache` | 缓存为空提示 | 无 |
| `admin.status-gun-ui-mode` | 枪械 UI 模式 | `{0}` - ax/mod |
| `admin.status-gun-ui-channel` | 模式推送通道 | `{0}` - 通道名 |
| `admin.status-gun-ui-unavailable` | 枪械 UI 服务未启动 | 无 |
| `admin.push-ok` | 推送成功 | `{0}` 玩家 `{1}` 模式 |
| `admin.push-notfound` | 玩家不在线 | `{0}` 玩家名 |
| `admin.push-unavailable` | 枪械 UI 服务未启动 | 无 |
| `admin.push-usage` | push 用法 | 无 |
| `help.title` | 帮助命令标题 | 无 |
| `help.status` | status 子命令帮助 | `{0}` - 根命令标签 |
| `help.push` | push 子命令帮助 | `{0}` - 根命令标签 |

## 自定义消息示例

在 `messages.yml` 对应小节修改标题和缓存提示，保留数量参数 `{0}`：

```yaml
admin:
  status-title: "&6物品提示状态"
  status-cache-size: "&7当前缓存玩家数: &f{0}"
```

保存后执行 `axs reload tooltip`，再用 `axs tooltip status` 核对模式和文案。
