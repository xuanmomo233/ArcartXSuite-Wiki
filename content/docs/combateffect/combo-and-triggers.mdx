连击、死亡缓冲、按键特效和 Chronos 状态联动可分别启用。

## 子系统概览

| 子系统 | 配置节 | 依赖 | 默认状态 |
|---|---|---|---|
| 连击追踪 | `combo-tracker` | Chronos（可选） | 禁用 |
| 死亡缓冲 | `death-buffer` | ArcartX（视觉）/ Chronos（可选） | 禁用 |
| 按键触发器 | `keybind-trigger` | ArcartX | 禁用 |
| 状态/控制器触发器 | `state-trigger` | Chronos | 禁用 |

> 四个子系统均默认禁用，需在 `config.yml` 中显式启用。启用时需确保对应依赖已安装，否则自动降级或保持禁用。

## 连击追踪

追踪玩家连续攻击次数，达到条件时触发特效包，并可实时同步连击数到客户端变量。

### 连击来源

连击来源通过 `combo-tracker.source` 配置，支持三种模式：

| 来源模式 | 配置值 | 说明 | 降级行为 |
|---|---|---|---|
| 自动检测 | `auto` | Symphony 确认桥可用时统计有效伤害。否则优先 Chronos，Chronos 不可用时统计有效伤害 | 按当前可用来源选择 |
| 仅 Chronos | `chronos` | 仅使用 Chronos 状态进入事件 | Chronos 不可用 → 不启用 |
| 有效伤害 | `bukkit` | 使用宿主结算后的 Symphony、Bukkit 与 TaCZ 伤害 | 可独立使用 Bukkit 或 TaCZ |

### Chronos 状态组过滤

Chronos 来源模式下，仅指定状态组的状态进入才计为连击一击：

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `combo-tracker.chronos-groups` | `["攻击", "连击"]` | 状态组过滤列表 |

### 超时重置

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `combo-tracker.timeout` | `2000` | 超时重置时间（毫秒），最小 200 |

连击超时或模块重载时，服务端向实时 HUD 推送 0，HUD 随即隐藏。

### 目标锁定模式

| `per-target` | 行为 | 适用场景 |
|---|---|---|
| `false`（默认） | 切换目标不重置，连续攻击任意目标均累加 | 群战、清怪 |
| `true` | 切换目标重置为 1，仅对同一目标的连续攻击累加 | Boss 战、单挑 |

按有效伤害计数时可使用 `per-target`。取消、闪避和零伤害均不增加连击。能识别为同一次 TaCZ 命中的多段伤害只增加一次连击。

### 客户端连击推送

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `combo-tracker.sync-variable` | `true` | 按变化推送实时连击数，关闭时 HUD 仍可接收阈值提示 |

默认 HUD 的 `combo_sync` 处理器接收整数。首击立即更新，后续同一 tick 内的普通更新合并，达到里程碑时保留该次连击数。自定义同 ID 的 HUD 可以用以下方式接收数据：

```yaml
ui:
  packetHandler:
    combo_sync: |-
      var.combo_count = Cast.toInt(packet)
```

控件直接读取 `var.combo_count`，随连击数更新显示。

### 连击包触发条件

`trigger: combo` 的包定义按以下条件触发：

| `combo-repeat` | `combo-min` | 触发时机 |
|---|---|---|
| `false` | `5` | 仅当连击数恰好达到 5 时触发一次 |
| `false` | `0` | 每一击都触发 |
| `true` | `5`（`combo-max=10`） | 5~10 连击范围内每一击都触发 |

> 连击特效仅发给攻击者自己。

## 死亡缓冲

在玩家受到致死伤害时拦截，给玩家一个可视化缓冲期后再真正死亡。

### 行为流程

1. 检测伤害是否致死。可用的手持图腾交给原版处理
2. 取消致命伤害，临时开启免伤并将移动速度设为零
3. 应用视觉效果（Shader、第三人称、预设相机、Chronos 状态）
4. 触发 `trigger: death` 的包定义
5. 缓冲到期或玩家退出时，清理缓冲状态并结算死亡

模块重载或停用时会撤销待结算的缓冲，恢复进入前的移动速度和免伤状态，并关闭内置死亡缓冲界面。

### 视觉效果

| 效果 | 配置项 | 说明 |
|---|---|---|
| Shader | `visuals.shader` | ArcartX Shader 名称（灰度/模糊等） |
| 第三人称视角 | `visuals.third-person-camera` | 切换到第三人称视角，缓冲结束后恢复 |
| 预设相机 | `visuals.camera-preset` | ArcartX 预设相机 ID |
| Chronos 状态 | `visuals.chronos.enabled` + `visuals.chronos.state-id` | 尝试进入当前控制器下的指定受控状态，受霸体窗口限制 |

> ArcartX 未安装时视觉效果不应用，但不影响缓冲流程。

### 缓冲配置

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `death-buffer.duration` | `3000` | 缓冲持续时间（毫秒），最小 500 |
| `death-buffer.abyss-packet-id` | `""` | Abyss 倒地后向玩家发送的特效包 ID。留空关闭发包 |
| `death-buffer.world-blacklist` | `[]` | 不启用死亡缓冲的世界列表 |

Abyss 管理副本内的倒地、图腾和救援。开启 `death-buffer.enabled` 后，可用 `abyss-packet-id` 指定一个已启用的特效包，例如用于倒地提示的 HUD。包模板可以引用 `{dungeon}`、`{instance}` 和 `{deaths}`。

### 死亡包接收者

| 接收者 | 实际接收 | 说明 |
|---|---|---|
| `target` | 被击杀的玩家 | 显示全屏死亡界面 |
| `attacker` | 击杀者 | 复用击杀特效 HUD 显示击杀提示 |

> 环境死亡（摔落、岩浆等）无击杀者，仅 `target` 接收者会收到死亡缓冲包。

## 按键触发器

监听 ArcartX 客户端按键事件，匹配 `trigger: keybind` 的包定义并发送特效。需要 ArcartX 安装且 `keybind-trigger.enabled=true`。

### 按键类型

| 按键类型 | 配置值 | 说明 |
|---|---|---|
| 客户端按键 | `client` | ArcartX 标准按键绑定（支持按下/释放） |
| 简易按键 | `simple` | 轻量按键（支持按下/释放） |
| 按键组 | `group` | 按键组按下事件（无释放事件） |

> 按键组仅有按下事件，`key-action: release` 对按键组类型无效。

### 匹配条件

| 匹配维度 | 条件字段 | 说明 |
|---|---|---|
| 按键名称 | `key-name` | 通配符匹配（`*` 匹配任意字符序列） |
| 按键类型 | `key-type` | `client`（客户端绑定） / `simple`（简易按键） / `group`（按键组） |
| 按键动作 | `key-action` | `press`（按下） / `release`（松开） / `both`（两者） |

### 按键触发示例

> 按键触发器的接收者始终为触发的玩家自身。变量替换支持 `{player}` 和 `{key_name}`。

## 状态/控制器触发器

监听 Chronos 状态进入/离开与控制器切换事件，匹配 `trigger: state` 和 `trigger: controller` 的包定义。需要 Chronos 安装且 `state-trigger.enabled=true`。

### 状态触发

| `state-action` | 触发时机 |
|---|---|
| `enter` | 进入状态时 |
| `leave` | 离开状态时 |
| `both` | 进入或离开均触发 |

| 匹配维度 | 条件字段 | 说明 |
|---|---|---|
| 状态 ID | `state-id` | 通配符匹配（`*` 匹配任意字符序列） |
| 动作 | `state-action` | `enter`（进入） / `leave`（离开） / `both`（两者） |
| 控制器过滤 | `controller-id` | 可选，通配符匹配；为空时不做控制器过滤 |

### 控制器触发

| `controller-id` 配置 | 匹配行为 |
|---|---|
| 未设置或为空 | 匹配所有控制器切换 |
| 设置值（如 `弓箭手`） | 仅匹配指定控制器 |
| 通配符（如 `mode_*`） | 通配符匹配控制器 ID |

### 状态/控制器触发示例

> 状态触发器的接收者始终为触发的玩家自身。变量替换支持 `{player}`、`{state_id}` 和 `{controller_id}`。

## Chronos 技能阶段特效

使用 Chronos 3.1.1。Suite 探测 Chronos 的动作实例和外部执行处理器能力，缺少能力时 `/axs combateffect status` 会显示 `UNSUPPORTED`。

在 CombatEffect 的 `config.yml` 开启技能特效。规则按 YAML 中的顺序取首条命中，技能、职业和槽位三个条件同时生效。留空或填写 `"*"` 可匹配该维度的任意值。

```yaml
skill-effects:
  enabled: true
  rules:
    charge:
      skill: "example:charge"
      profession: "example:warrior"
      slot: "primary"
      hud-text: "蓄力中"
      start-packets: []
      cleanup-packets: []
```

- `start-packets` 引用 `packets/` 中已启用的包 ID，在技能首次进入状态时按顺序发送一次。
- `hud-text` 挂载内置 `AXS:skill_effect_hud`，在技能状态切换期间持续显示。留空可只用包特效。
- `cleanup-packets` 用于清除自定义脚本启动的效果，只发送到这个动作已经挂载的 UI。动作结束、打断或模块重载时，CombatEffect 取消待发包并关闭该动作打开的所有 UI。自定义特效包应指向技能专用 UI。

### 在动作时间点播放包

在 CombatEffect 的 `packets/` 新建 `charge.yml`，使用内置 HUD 显示释放提示。

```yaml
charge-release:
  trigger: manual
  ui-id: "AXS:skill_effect_hud"
  packet-handler: "show"
  pack:
    text: "释放"
```

在 Chronos 技能使用的状态中配置 `execute`。以下在状态开始后的 300 毫秒调用特效包，时间域和状态速度沿用 Chronos 的规则。首次打开某个特效界面时，CombatEffect 下一 tick 发包以等待挂载。

```yaml
execute:
  release-effect:
    at: 300
    handler: "axs:play_effect"
    args:
      packet-id: "charge-release"
```

在当前技能动作中调用处理器，即可向施放者发送特效包。包模板可用 `{skill_id}`、`{skill_level}`、`{profession_id}`、`{slot_id}`、`{action_instance_id}` 和 `{state_id}`。时间点触发另提供 `{state_instance_id}`、`{execution_id}` 和 `{execution_index}`，并遵循包的 `cooldown`。清理包可读取 `{end_reason}`，停用或重载时为 `shutdown`。

保存后执行 `/axs reload combateffect`。重载时正在施放的技能会清理旧效果，下次施放使用新配置。

## 冷却

连击追踪的包分发不使用冷却（由 `combo-min` / `combo-max` / `combo-repeat` 条件控制频率）。按键触发器和状态/控制器触发器均支持独立冷却，与包定义系统冷却行为一致。参考 [包定义系统](/docs/combateffect/packet-definitions#冷却系统)。
