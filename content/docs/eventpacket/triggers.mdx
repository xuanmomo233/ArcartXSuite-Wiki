---
title: "事件触发器"
description: "按实时消息、信号、定时或确认的业务结果选择触发规则。"
---

| `trigger` | 要填写的字段 | 用途 |
| --- | --- | --- |
| `event-bus` | `topic` | 接收 Suite 事件。例如 `axs.fishing.success` 或 `axs.questgps.quest_completed`。 |
| `signal` | `signal` | 接收管理员命令、菜单或其他模块发送的同名信号。 |
| `schedule` | `schedule` | 按周期运行控制台命令，见[定时命令](/docs/eventpacket/services)。 |
| `abyss-result` | `when.dungeon` | 用已结算的副本结果发邮件。可用 `when.difficulty` 限定难度，`owner` 默认 `abyss`。 [副本通关邮件的单服与跨服条件](/docs/eventpacket/actions#副本通关邮件) |
| `first-admitted` | — | 玩家第一次通过准入时发邮件。 |
| `auction-purchased` | — | 拍卖到期成交后向买家发邮件。 |

已安装并启用 EventPacket 的服务器会保留模块启动或暂时停止期间的拍卖成交事件，模块恢复后继续按配置处理。

共用 Market 拍卖库时，所有结算服须启用 EventPacket，并使用相同成交规则和同一套 EventPacket、Mail 存储。

## 钓到传奇鱼时提示

```yaml
rules:
  legendary-fishing:
    trigger: event-bus
    topic: axs.fishing.success
    when:
      fish_rarity: LEGENDARY
    actions:
      - type: message
        text: "你钓到了一条传奇鱼！"
```

把规则加入 `rules` 并重载。用具备对应钓鱼条件的玩家完成一次传奇鱼捕获，核对提示。
