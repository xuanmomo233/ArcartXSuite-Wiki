编辑 `plugins/ArcartX-Suite/data/eventpacket/config.yml`，在 `rules` 中为每条规则设置一个独立的 ID。

## 测试一条信号规则

将 `trial-open-message` 合并到现有的 `rules` 段。

```yaml
rules:
  trial-open-message:
    enabled: true
    trigger: signal
    signal: trial_open
    actions:
      - type: message
        text: "试炼入口已触发。"
```

保存并执行 `/axs reload eventpacket`。执行 `/axs eventpacket fire trial_open WikiTester`，检查对应玩家是否收到消息。

## 规则字段

| 字段 | 用途 |
| --- | --- |
| `enabled` | 是否启用规则，默认 `true`。 |
| `trigger` | 何时执行，见[触发器](/docs/eventpacket/triggers)。 |
| `when` | 按事件字段精确匹配，填写的条件须全部满足。值可以填字符串、数字或布尔值。 |
| `actions` | 按顺序执行的动作列表，每条规则可填写 1 至 8 个动作。 |

规则 ID 和信号名使用小写字母、数字、连字符或下划线，以字母或数字开头，最多 64 个字符。主配置最多可填写 256 条规则。

## 实时规则处理上限

| 字段 | 默认 | 用途 |
| --- | --- | --- |
| `runtime.queue-capacity` | `1024` | 待处理事件队列容量，取值 16 至 8192。 |
| `runtime.work-per-tick` | `64` | 每 tick 的处理量上限，取值 1 至 512。 |
| `runtime.budget-micros` | `750` | 每 tick 处理预算，单位为微秒，取值 100 至 5000。 |

可以用 `/axs eventpacket status` 查看实时队列与丢弃计数。
