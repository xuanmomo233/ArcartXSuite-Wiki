## 实时动作

| 动作类型 | 用途 | 参数示例 |
| --- | --- | --- |
| `subtitle` | 播放 Announcer 字幕组。 | `group: welcome_demo` |
| `quest.offer` | 通过 QuestGPS 向玩家展示可接取任务。 | `quest: chapter_two`、`open-menu: true` |
| `quest.track` | 通过 QuestGPS 追踪已接取任务。 | `quest: chapter_two` |
| `message` | 向玩家发送聊天栏提示。 | `text: "已解锁下一阶段"` |
| `command` | 以控制台或玩家身份执行固定命令。 | `executor: console`、`command: save-all` |

字幕和任务动作分别需要 Announcer 和 QuestGPS。消息、字幕组和任务 ID 支持引用事件字段，例如 `{quest_id}`。命令使用固定参数，`executor` 可选 `console` 或 `player`。执行玩家动作时，目标玩家须在线且已通过准入。

## 副本通关邮件

```yaml
rules:
  abyss-clear:
    enabled: false
    trigger: abyss-result
    when:
      dungeon: example_dungeon
      difficulty: hard
      outcome: COMPLETED
    actions:
      - type: mail
        id: clear-reward
        title: "副本通关奖励"
        content: "你已通关 {dungeon}，难度 {difficulty}。"
        currency: money
        amount: 100
```

将副本、难度和货币 ID 换成实际配置，确认 Abyss 和 Mail 已加载后启用规则。发放奖励后保持规则 ID 和邮件动作 `id` 稳定，便于防止同一结果重复发放。只发通知时可省略 `currency` 和 `amount`。省略 `start-sequence` 时，规则从启用时的副本结果游标开始处理。需要多服发放时，EventPacket、Abyss 和 Mail 使用同一个 Suite 共享 MySQL。
