以下命令需要 `arcartxsuite.admin`。

| 命令 | 说明 |
| --- | --- |
| `/axs reload eventpacket` | 读取主配置并应用规则。 |
| `/axs eventpacket status` | 查看实时队列、丢弃量、动作失败数和持久规则状态。 |
| `/axs eventpacket topics` | 列出实时主题和副本规则 ID。 |
| `/axs eventpacket fire <信号> <玩家> [key=value...]` | 向指定在线玩家触发信号，可附加字段和取值。 |
| `/axs eventpacket cleanup` | 手动发起一轮本服实体清理，结束后向执行者显示清理数量。 |

状态显示「共享 MySQL 副本结果编排需要客户版有效授权」时，请核对当前服务器的 EventPacket 客户水印席位和同批次安装包。单服可用 SQLite 运行[副本通关邮件规则](/docs/eventpacket/actions#副本通关邮件)。

### 测试信号

按[规则示例](/docs/eventpacket/configuration#测试一条信号规则)发送信号。显示「信号已入队」后，核对玩家收到的消息。命令提交失败时，检查信号名、玩家准入状态和队列容量。入队后未收到消息时，用 `/axs eventpacket topics` 检查规则是否注册，用 `/axs eventpacket status` 查看动作失败计数。

手动清理使用 [`cleanup.yml` 的规则](/docs/eventpacket/services#定时与手动实体清理)。开启 `enabled` 并重载后即可运行。
