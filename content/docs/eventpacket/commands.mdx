description: "手动触发信号、查看已注册的主题和规则处理状态。"
---

以下命令需要 `arcartxsuite.admin`。

| 命令 | 说明 |
| --- | --- |
| `/axs reload eventpacket` | 读取主配置并应用规则。 |
| `/axs eventpacket status` | 查看实时队列、丢弃量、动作失败数和持久规则状态。 |
| `/axs eventpacket topics` | 列出实时主题和副本规则 ID。 |
| `/axs eventpacket fire <信号> <玩家> [key=value...]` | 向指定在线玩家触发信号，可附加字段和取值。 |

副本结果查不到时，系统会稍后重试补记。Mail 和数据库可用时，已经登记的邮件会继续发送。

### 测试信号

```text
/axs eventpacket fire trial_open WikiTester
```

将命令目标改为已通过进服验证的在线玩家。显示「信号已入队」后，检查[规则示例](/docs/eventpacket/configuration#测试一条信号规则)的提示。提交失败时，核对信号名、规则开关、玩家登录状态和队列容量。
