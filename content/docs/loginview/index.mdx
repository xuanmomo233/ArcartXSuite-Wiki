---
title: "登录认证"
description: "按玩家使用的账号和连接方式选择 LoginView 登录流程，设置进服要求并检查是否放行。"
---

LoginView 在玩家进入服务器时显示当前要做的事。使用本服密码的玩家在游戏里注册或登录。使用在线账号的玩家先由 Minecraft、代理或认证中心验证身份。服主开启了条款或 QQ 绑定时，玩家完成这些要求后才能移动和交互。

## 第一次使用

先阅读[使用入门](/docs/loginview/getting-started)，确认模块装在哪里、认证入口由哪份文件控制。已经装好 LoginView 的服主可以直接按下表选教程。

## 选择登录入口

| 你的玩家怎样进服 | 去哪里配置 |
| --- | --- |
| 玩家连接离线服的 IP 或域名，首次在游戏内注册，以后输入本服密码登录 | [离线模式与游戏内密码](/docs/loginview/password-login) |
| 玩家用微软账号直连，服务器沿用 Minecraft 原生在线验证 | [微软账号直连](/docs/loginview/online-login) |
| 微软、LittleSkin 等不同来源的账号直连同一台游戏服 | [单服混合认证](/docs/loginview/mixed-login#单服混合认证) |
| 玩家先连接 Velocity 或 BungeeCord，再进入子服 | [代理转发认证](/docs/loginview/mixed-login#代理转发认证) |
| 玩家已经连进游戏，需要用官网或启动器确认这一次连接 | [认证中心与官网授权](/docs/loginview/center) |

希望玩家**用官网账号启动 Minecraft** 时，先在认证中心[登记启动器](/docs/loginview/center#登记启动器)，再把中心接入[混合登录网关](/docs/loginview/mixed-login#加入-suite-authcenter)。这条路在玩家启动游戏前取得 Minecraft 会话。

## 配置验证

用普通玩家账号进服。第一次连接应出现所选教程描述的界面或握手结果。若玩家还需同意条款或绑定 QQ，操作会受到限制。完成最后一项要求后，确认玩家可以正常移动、打开容器。服主还可以[查询玩家账号](/docs/loginview/commands#认证状态查询)，分别核对身份来源和最终放行状态。

## 相关文档

- 要求玩家阅读服规或绑定 QQ 时，按[准入要求与登录界面](/docs/loginview/configuration)设置，并用一个尚未完成要求的账号验收。
- 玩家卡在某一步时，按[管理命令与故障排查](/docs/loginview/commands)核对当前连接。自研启动器使用[启动器授权接口](/docs/loginview/external-api)接入中心。
