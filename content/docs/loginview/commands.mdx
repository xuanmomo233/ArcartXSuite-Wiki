## 常用命令

以下是游戏服的管理命令。玩家执行时需要 `arcartxsuite.admin`，游戏服控制台执行时省略开头的 `/`。

| 命令 | 什么时候用 | 预期结果 |
| --- | --- | --- |
| `/axs status` | 开服后检查安装 | 在模块列表中确认 LoginView 的加载状态 |
| `/axs loginview status` | 检查模块指令是否已注册 | 返回 LoginView 负责界面、宿主负责认证的说明 |
| `/axs loginview account <玩家>` | 查询本服在线玩家的账号 | 显示账号 ID、登记状态、身份来源、验证结果、游戏准入及当前阶段 |
| `/axs loginview open <玩家>` | 为在线玩家重新打开当前步骤 | 待登录或待准入的玩家看到相应界面，已放行的本服密码玩家可修改密码 |
| `/axs reload loginview` | 修改界面打开延迟后 | 模块重新读取延迟并注册内置界面。修改 `authentication.yml` 需要重启游戏服 |
| `/axs unload loginview` | 管理员主动停止使用该模块 | Suite 解除 LoginView 的限制，其他插件继续管理自己的进服规则 |

## 账号管理界面

游戏内密码玩家通过当前登录后，管理员可执行 `/axs loginview open 玩家名`。玩家在账号界面填写旧密码、新密码并确认新密码。改好后重新连接，用新密码登录。已放行的外部账号执行同一操作时会收到前往身份提供方管理密码的提示。

## 认证状态查询

在游戏服控制台执行 `axs loginview account Alex`，将 `Alex` 换成本服在线玩家的完整名字。管理员在游戏内执行时加上 `/`。该命令直接读取当前连接的账号状态，无需安装 PlaceholderAPI。

例如，微软账号已完成握手、正在等待确认服规时，会看到 `身份来源 microsoft`、`身份验证 已通过`、`游戏准入 未放行` 和 `当前阶段 awaiting_requirements`。确认条款并完成其余要求后，再查应显示 `游戏准入 已放行` 和 `当前阶段 admitted`。玩家离线时命令会给出提示。

### 使用占位符查询

已安装 PlaceholderAPI 的服务器也可以在控制台执行 `papi parse Alex %axsauth_stage%`。玩家有 PlaceholderAPI 查询权限时，可以用 `/papi parse me %axsauth_admitted%` 查看自己。

| 占位符 | 怎样解读 |
| --- | --- |
| `%axsauth_stage%` | `awaiting_identity` 表示等待身份验证，`awaiting_requirements` 表示等待条款或绑定，`admitted` 表示已放行。还可能返回 `absent`、`loading`、`restricted` 或 `closed` |
| `%axsauth_verified%` | 已确认账号身份时返回 `true` |
| `%axsauth_admitted%` | 当前连接已获准参与游戏时返回 `true`。检查能否操作时看此项 |
| `%axsauth_provider%` | 当前身份来源，如 `local-password`、`microsoft`、`littleskin`、`center` 或 `oidc`。来源尚未确定时返回 `unknown` |
| `%axsauth_registered%` | 账号登记状态，可能为 `registered`、`unregistered` 或 `unknown` |

如果 `verified=true`、`admitted=false`，优先查看玩家界面剩余的准入要求。开启其他登录插件的服，还应按该插件自己的状态判断其登录是否完成。

## 故障排查

| 玩家或服主看到的现象 | 先检查什么 |
| --- | --- |
| 新玩家直接进服，看不到预期的注册或条款界面 | 用 `axs status` 检查模块，再核对该账号的登录方式与待办要求。微软原生在线验证且无附加要求时会直接放行 |
| 有待办要求，但玩家看不到界面 | 检查客户端 ArcartX、服务端界面加载日志和玩家是否在线。用 `/axs loginview open <玩家>` 重开该玩家的当前步骤 |
| 离线服没有出现注册或登录界面 | 确认 LoginView 已启用、`online-mode=false`，直连游戏服已关闭代理转发。将 `standalone` 后端的入口设为 `auto` 或 `password`。[设置离线直连](/docs/loginview/password-login#设置离线直连) |
| 选了单服混合登录却收不到握手结果 | 检查实际启动的脚本、`-javaagent` 所用网关和 `ingress.gateway-url` 的端口。[配置游戏服入口](/docs/loginview/mixed-login#配置游戏服入口) |
| 能进代理，在子服一直等待身份验证 | 核对子服注册名、玩家信息转发、签发者、公钥、Realm、目标标识和允许的来源。[配置子服信任项](/docs/loginview/mixed-login#配置子服信任项) |
| 长时间在线后切服才被拒绝 | 代理上的原始认证已超过 12 小时时，断开并重新连接代理，再进入目标子服 |
| 中心启动报缺少字段或密钥 | 核对完整 `center.json` 的必填字段，以及中心**进程**实际取得的节点密钥和 OIDC 应用密钥。[编写中心配置](/docs/loginview/center#编写中心配置) |
| 中心已启动，游戏节点仍连不上 | 确认节点连接节点端口，核对 Realm、节点 ID、目标标识、密钥值和系统时间。[游戏节点配置](/docs/loginview/center#游戏节点配置) |
| 网页已授权，游戏还在等待 | 回到发起授权的那一次游戏连接，刷新、比对核对码、点击确认，再完成条款或绑定。[游戏内确认步骤](/docs/loginview/center#玩家在游戏内确认授权) |
