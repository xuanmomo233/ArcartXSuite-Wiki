description: "设置同机离线登录，让新玩家注册、老玩家在游戏内输入密码，并验证输错密码和重新进服的结果。"

选择这条路线时，玩家在 LoginView 输入本服密码。当前 Suite 要求客户端与游戏服在同一台机器上，通过回环地址直连。这里的离线模式指 Minecraft 的 `online-mode=false`。如果玩家从其他机器或代理进入，按[连接方式](/docs/loginview#选择登录入口)选相应入口。

## 设置离线直连

1. 完成[启用 LoginView](/docs/loginview/getting-started#启用-loginview)，停服后编辑游戏服根目录的 `server.properties`。

   ```properties
   online-mode=false
   server-ip=127.0.0.1
   ```

2. 将游戏服 `spigot.yml` 中的 `settings.bungeecord` 设为 `false`。使用 Paper 时，同时关闭 `config/paper-global.yml` 中的 `proxies.velocity.enabled`。
3. 玩家稍后在这台机器上使用 `127.0.0.1` 和游戏服实际端口连接。使用 IPv6 回环时，监听地址改为 `::1`，客户端使用 `[::1]:端口`。

## 配置密码入口

将以下配置写入 `plugins/ArcartX-Suite/authentication.yml`。`local` 是新服示例，已有服保留自己的 `realm-id`。

```yaml
schema-version: 1
backend: standalone
realm-id: local
ingress:
  type: password
  password-login: true
password:
  min-length: 8
  max-length: 128
  max-attempts: 5
  cooldown-seconds: 300
requirements:
  terms: false
  qq-binding: false
```

这个示例接受 8 至 128 个字符的密码，连续输错达到 5 次会进入 300 秒冷却。先单独验收注册、登录。需要玩家确认服规或绑定 QQ 时，再开启相应的[准入要求](/docs/loginview/configuration#准入要求)。

## 注册与重新登录

1. 启动游戏服，在控制台执行 `axs status`，确认 LoginView 已启用。
2. 从同机客户端使用一个新玩家名连接。注册界面填写密码，再输入一次确认。提交后应能移动和交互。
3. 断开连接，用同一个玩家名重新进服。这次应出现登录界面。先输错一次，确认仍受限，再提交正确密码，确认可以游戏。
4. 需要修改密码时，让管理员为这名已登录的在线玩家打开[账号管理界面](/docs/loginview/commands#账号管理界面)。改好后断开，用新密码重连验收。

启动日志提示密码入口只支持本机直连时，检查实际生效的 `online-mode`、`server-ip` 和两种转发开关。监听地址留空或填 `0.0.0.0` 都不能启用这个入口。
