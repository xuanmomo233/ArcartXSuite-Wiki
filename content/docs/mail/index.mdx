## 开始前

安装 `PlaceholderAPI`，用 `/axs status` 确认模块已加载。

## 第一次使用

1. 编辑一个默认预设。
2. 按命令页向测试玩家发送。
3. 执行 `/mail` 打开收件箱。

## 检查是否配置成功

阅读邮件并领取附件，确认物品或货币到账。

修改预设后，用 `/axs mail preset send trial_supply WikiTester` 重新派发。未收到时核对预设 ID 与收件人，缺少附件时查看[预设与领取步骤](/docs/mail/presets#预设派发与附件领取示例)。

## 玩家寄信结果待核对

关闭写信界面或离服后，未寄出的附件会尝试返还。异常中断后，请回原服完成登录，等待核对。背包空间不足时，腾出空间并重新打开写信界面。提示待核对时，请联系管理员查看原服附件记录和背包存档。重新写信时需填写收件人、标题和正文。

增减附件或打开写信界面时，请等后台核对完成。背包或会话在等待期间发生变化时，本次尚未执行的附件操作会取消，可按界面提示重试。

寄信前会确认物品附件已扣除，收费邮件会保留扣款凭证。提示「扣款待核对」时，将编号交给管理员查经济流水。提示「寄信结果待核对」时，回到原服重新打开写信界面查询。

寄信成功后由收件人在收件箱查看。确认未寄出时，发件人登录后系统会尝试退回已扣除的费用和可退附件。结果待核对时，将凭证编号交给管理员。

附件或退款持续待核对时，请将凭证编号交给管理员。在 `plugins/ArcartX-Suite/data/mail/send-review/` 查找记录，核对收件箱、经济流水和发件人背包存档。

## 可以配置的功能

| 特性 | 说明 |
|---|---|
| 收件箱系统 | ArcartX UI 驱动的收件箱界面，支持分页浏览、来源筛选、预览、领取和删除 |
| 玩家写信 | 玩家可向其他玩家发送邮件，支持物品附件和 Vault 货币附件，含手续费与税率 |
| 预设邮件 | 管理员预设邮件模板，支持批量派发给在线玩家或全部注册玩家，含二次确认机制 |
| 物品附件 | 支持原版、MythicMobs、NeigeItems、Overture、MMOItems 物品库产物，含 Base64 完整序列化 |
| 货币附件 | 支持 Vault 金币和多货币系统附件，货币附件可自定义展示图标 |
| 领取条件 | 预设邮件支持 `claim-conditions` 领取条件，使用 ScriptCondition 引擎（PAPI/Aria/JS） |
| 领取命令 | 预设邮件支持 `claim-commands` 领取时执行命令，支持 `{player}` 等变量 |
| 内容审核 | 敏感词、正则、物品材质、Lore 正则、物品名称正则、NBT/PDC 键值屏蔽 |
| 跨服广播 | 多服邮件刷新通知（Redis + Proxy 双后端），收件人上线自动刷新收件箱 |
