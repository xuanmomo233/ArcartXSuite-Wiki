| 项目 | 说明 |
| --- | --- |
| 模块 ID | `prop` |
| 主配置 | `plugins/ArcartX-Suite/data/prop/config.yml` |
| 道具定义 | `plugins/ArcartX-Suite/data/prop/props/` |
| 重载 | `/axs reload prop` |

## 开始前

在 Suite 本体的 `config.yml` 中启用 `modules.prop.enabled`，并确认服务端已加载 ArcartX。执行 `/axs prop status` 查看道具数和桥接状态。快捷键使用需要匹配的 ArcartX 客户端与已配置的额外槽位。属性类道具还需要相应的[属性提供方](/docs/prop/effects#属性组)。

## 第一次使用

下面定义一份补给，主手右键使用时恢复 6 点饱食度、消耗 1 个物品并进入 10 秒冷却。

```yaml
# data/prop/props/field_ration.yml
name: "野外补给"
coolDownGroup: "野外补给"
coolDownTime: 10
remove: true
hand: true
key: true
effects:
  food: 6
  messages:
    - "&a你使用了野外补给。"
```

1. 保存为 `props/field_ration.yml`，执行 `/axs reload prop`。
2. 管理员将要发放的物品拿在主手，执行 `/axs prop set field_ration`。要绑定一叠补给，直接手持整叠执行命令。
3. 玩家拿到绑定后的物品，在饱食度未满时主手右键。

道具 ID 来自 `props/` 下的相对路径，例如 `supplies/field_ration.yml` 对应 `supplies/field_ration`。绑定后的物品按该 ID 读取效果。调整定义后重载，同一 ID 的已绑定物品会读取新定义。

## 检查是否配置成功

首次使用应显示补给提示并消耗一个物品，冷却期间再次使用会显示剩余时间。用 `/axs prop status` 检查加载状态，用 `/axs prop set` 的补全核对道具 ID。快捷槽的三个槽位 ID 须一致。 [槽位绑定](/docs/prop/keybinds#配置按键与槽位)

## 可以配置的功能

| 特性 | 说明 |
|------|------|
| 客户端按键绑定 | 通过 ArcartX 客户端按键系统将道具槽位绑定到键盘按键，按下即触发使用 |
| 手持右键使用 | 将任意物品绑定为指定道具后，玩家手持右键即可触发 |
| 多槽位支持 | 支持配置多个快捷道具槽位（Slot1/Slot2/Slot3...），每个槽位独立绑定按键 |
| 冷却组 | 同一冷却组内的多个道具共享冷却时间，避免重复使用 |
| 物品消耗 | 使用后可选消耗一个物品（`remove: true`）或保留物品（`remove: false`） |
| 权限控制 | 每个道具可配置使用权限节点，留空表示无限制 |
| 使用条件 | 按玩家数据判断道具是否可用，支持 PAPI 比较、Aria 条件等写法 |
| 自动触发 | 定期检查绑定槽位，可按低血量等条件自动使用 |
| 效果系统 | 配置即时效果、药水和独立计时的属性组，支持 AttributePlus、CraneAttribute、MythicLib、Symphony 和 Forge 模组属性 |
| 动态数值 | 属性加成可用 Aria 计算，读取玩家等级、Symphony 属性或 PAPI 数值 |
| 快捷使用真实物品 | 可单独为原版药水和受支持的 MMOItems 右键动作配置按键模式 |
