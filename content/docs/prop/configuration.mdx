## 配置文件

以下路径均相对于 `plugins/ArcartX-Suite/`。模块首次启动时会导出缺失的默认文件。修改 Prop 文件后执行 `/axs reload prop`。

| 文件 | 路径 | 说明 |
|------|------|------|
| 主配置 | `data/prop/config.yml` | 调试开关、MythicLib 前缀、自动触发轮询 |
| 按键映射 | `data/prop/key.yml` | 客户端按键分类与槽位绑定 |
| 语言文件 | `data/prop/language.yml` | 冷却、权限、条件等提示消息 |
| 道具定义 | `data/prop/props/` | 支持子目录，每个 `.yml` 或 `.yaml` 文件定义一个道具 |
| 消息文件 | `data/prop/messages.yml` | 管理命令、属性不可用、公式错误和槽位写入提示 |

## 主配置（`config.yml`）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `config-version` | `int` | `1` | 配置版本号，由模块自动管理，不要手动修改 |
| `settings.debug` | `boolean` | `false` | 是否输出调试日志（按键注册、使用成功、效果跳过等） |
| `mythiclib.source-prefix` | `string` | `AXS_PROP` | MythicLib 临时属性来源的命名前缀 |
| `auto-trigger.enabled` | `boolean` | `false` | 自动触发总开关。开启后服务端按固定间隔轮询在线玩家的快捷槽，自动使用满足触发条件的道具 |
| `auto-trigger.interval` | `int` | `20` | 全局轮询间隔（tick，20 = 1 秒）。道具 `auto.interval` 可覆盖，但实际粒度不会比该值更细 |
| `auto-trigger.mode` | `string` | `all` | 同轮多个槽位道具满足触发条件时的模式：`all` 全部尝试触发，`first` 第一个成功触发后停止本轮 |

```yaml
# 配置版本号（不要手动修改，由模块自动管理）
config-version: 1

settings:
  # 是否输出调试日志
  debug: false

mythiclib:
  # 临时属性 modifier 前缀。
  # 是否生效由本体 config.yml 的 attribute-bridges.mythiclib 统一管理。
  # 最终会生成:
  #   <前缀>_<道具属性组的稳定标识>_<属性 ID>
  source-prefix: "AXS_PROP"

auto-trigger:
  # 自动触发总开关。开启后服务端按固定间隔轮询在线玩家的快捷槽，
  # 对配置了 auto.enabled 且满足 auto.conditions 的道具自动执行使用流程。
  enabled: false
  # 全局轮询间隔（tick，20 = 1 秒）。
  # 单个道具可用 auto.interval 覆盖，但实际检查粒度不会比该值更细。
  interval: 20
  # 同一轮多个槽位道具同时满足触发条件时的处理模式:
  #   all   -> 全部尝试触发（各自受自己的冷却组限制）
  #   first -> 按槽位顺序，第一个成功触发后停止本轮
  mode: "all"
```

## 按键映射（`data/prop/key.yml`）

这里填写客户端按键分类与 ArcartX 额外槽位 ID。[额外槽位和界面写法](/docs/prop/keybinds#配置按键与槽位) · [MMOItems 普通按键和潜行按键示例](/docs/prop/keybinds#同一个按键触发两种技能)

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `category` | `string` | `ArcartX 快捷道具按键` | 客户端按键分类显示名称，玩家在按键设置中看到的分类名 |
| `keys.<绑定ID>.defaultKey` | `string` | `X` | 默认按键（客户端按键名，如 `Z` / `X` / `C`） |
| `keys.<绑定ID>.slot` | `string` | `Slot1` | 绑定的道具槽位标识（`Slot1` / `Slot2` / `Slot3`...） |
| `keys.<绑定ID>.mode` | `string` | `prop` | `prop` 使用已绑定道具，`vanilla-potion` 使用槽位里的原版药水，`mmoitems` 使用支持的 MMOItems 右键动作 |

```yaml
# 客户端按键分类名。
category: "ArcartX 快捷道具按键"

keys:
  # 顶层键是显示给玩家的按键名称。
  快捷道具1:
    # 默认按键（客户端按键名）
    defaultKey: "Z"
    # 绑定的道具槽位
    slot: Slot1
  快捷道具2:
    defaultKey: "X"
    slot: Slot2
  快捷道具3:
    defaultKey: "C"
    slot: Slot3
```

## 语言文件（`data/prop/language.yml`）

语言文件支持 `&` 颜色码和表中列出的占位符。`{item}` 优先使用定义的 `name`，省略时读取物品显示名。属性和公式故障提示在同目录的 `messages.yml` 中修改。

| 配置项 | 占位符 | 说明 |
|--------|--------|------|
| `COOL_DOWN` | `{item}` `{remaining_seconds}` | 冷却中提示，`{remaining_seconds}` 为剩余秒数（保留两位小数） |
| `NO_PERMISSION` | `{item}` | 无权限使用提示 |
| `NO_KEY` | `{item}` | 无法通过按键使用提示（`key: false`） |
| `NO_HAND` | `{item}` | 无法手持右键使用提示（`hand: false`） |
| `CONDITION_NOT_MET` | `{item}` `{condition}` | 使用条件不满足提示，`{condition}` 为未满足的条件原文 |
| `AUTO_USED` | `{item}` | 自动触发成功提示（道具 `auto.notify` 控制是否发送） |

```yaml
# {item} 为道具名，{remaining_seconds} 为剩余冷却秒数。
COOL_DOWN: "&7[&dArcartXProp&7]&c{item}&f还在冷却,你还需要等待&a{remaining_seconds}秒&f才能使用道具"
NO_PERMISSION: "&7[&dArcartXProp&7]&f你没有权限使用 &c{item}"
NO_KEY: "&7[&dArcartXProp&7]&c{item} &f无法按键使用"
NO_HAND: "&7[&dArcartXProp&7]&c{item} &f该道具无法手持使用"

# {item} 为道具名，{condition} 为未满足的条件原文。
CONDITION_NOT_MET: "&7[&dArcartXProp&7]&c{item} &f使用条件不满足: &e{condition}"

# {item} 为道具名。自动触发成功时发送（道具 auto.notify 控制开关）。
AUTO_USED: "&7[&dArcartXProp&7]&f已自动使用 &a{item}"
```

## 道具定义（`data/prop/props/*.yml`）

每个 YAML 文件定义一个道具。以 `props/` 为根取相对路径，去掉扩展名得到道具 ID。例如 `props/potions/heal.yml` 的 ID 是 `potions/heal`。查询道具时忽略大小写，同一 ID 只能定义一次。修改文件路径后，原先绑定该 ID 的物品需要重新绑定。

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `name` | `string` | 物品显示名 | 道具使用提示中的名称 |
| `coolDownGroup` | `string` | `默认冷却组` | 冷却组名称，同组道具共享冷却时间 |
| `coolDownTime` | `int` | `10` | 冷却秒数，`0` 表示该次使用无冷却 |
| `remove` | `boolean` | `true` | 使用后是否消耗一个物品 |
| `hand` | `boolean` | `true` | 是否允许手持右键使用 |
| `key` | `boolean` | `true` | 是否允许客户端按键触发 |
| `permission` | `string` | `""` | 使用所需权限节点，留空表示无限制 |
| `conditions` | 列表或配置节 | `[]` | 手持、按键和自动触发都要满足的条件 |
| `effects` | 配置节 | 必填 | 即时效果、药水和属性组。只需填写道具用到的字段 |
| `auto.enabled` | `boolean` | `false` | 是否启用自动触发（整节可省略）。独立于 `hand` / `key` 开关 |
| `auto.interval` | `int` | `0` | 该道具的检查间隔（tick）；`0` 或缺省表示使用全局 `auto-trigger.interval` |
| `auto.notify` | `boolean` | `true` | 自动使用成功时是否给玩家发送 `AUTO_USED` 提示 |
| `auto.conditions` | 列表或配置节 | `[]` | 自动触发额外需要满足的条件 |

> `coolDownGroup` 为空时会回退为 `默认冷却组` 并输出警告日志。`coolDownTime` 的负值会归零。

自动触发扫描 `key.yml` 指向的额外槽位。开启方式、扫描顺序与急救包示例见[自动触发](/docs/prop/keybinds#自动触发)。

### 效果格式

在 `effects` 中按字段配置即时效果，在 `potions` 和 `attributes` 中分别配置药水和属性组。每项药水和每个属性组都需要自己的 `duration`，单位为秒。字段说明和 TaCZ 示例见[效果系统](/docs/prop/effects)。

### 条件格式

多个条件需要全部满足。可以把 PAPI 比较和 Aria 条件放在同一列表里。例如设置道具需在 `world` 使用，并要求原版经验等级达到 5：

```yaml
conditions:
  - "%player_world% == world"
  - "aria: global.player.getLevel() >= 5"
```

Prop 道具条件中的 Aria 通过 `global.player` 访问玩家。属性 `amount` 公式使用自己的 `global.stats` 和 `global.level`。PAPI 比较支持 `==`、`!=`、`>=`、`<=`、`>`、`<`、`contains` 和 `regex`，需要对应的占位符扩展。列表也可用结构化条件对象，字段见[条件系统](/docs/guide/conditions)。

若条件无法解析，`conditions` 会使该道具无法加载，`auto.conditions` 会停用该道具的自动触发。重载日志会给出文件或道具 ID。

### 道具定义示例

```yaml
# data/prop/props/治疗药水.yml
name: "治疗药水"
coolDownGroup: "治疗冷却组"
coolDownTime: 30
remove: true
hand: true
key: true
permission: "arcartxsuite.prop.heal"

conditions:
  - "%player_level% >= 5"
  - "%player_health% < 20"

# 自动触发：当前生命值低于 8 点时尝试使用（需开启全局自动触发）
auto:
  enabled: true
  interval: 20
  notify: true
  conditions:
    - "%player_health% < 8"

effects:
  health:
    points: 10
  potions:
    - id: minecraft:regeneration
      level: 2
      duration: 10
  messages:
    - "&a你使用了治疗药水！"
  commands:
    - "say {player} 使用了治疗药水"
```

### 属性道具示例

```yaml
# data/prop/props/力量卷轴.yml
name: "力量卷轴"
coolDownGroup: "增益冷却组"
coolDownTime: 60
remove: true
hand: false
key: true
permission: ""

conditions: []

effects:
  attributes:
    mythiclib:
      damage:
        duration: 30
        modifiers:
          - id: ATTACK_DAMAGE
            amount: 5
  potions:
    - id: minecraft:strength
      duration: 10
```
