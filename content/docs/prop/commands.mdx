## 命令

| 命令 | 权限 | 说明 |
|------|------|------|
| `/axs prop help` | `arcartxsuite.admin` | 查看可用子命令列表 |
| `/axs prop status` | `arcartxsuite.admin` | 查看已加载道具数、已注册按键数与各属性桥接状态 |
| `/axs prop set <道具ID>` | `arcartxsuite.admin` | 将玩家主手物品绑定为指定道具 |
| `/axs reload prop` | `arcartxsuite.admin` | 重新加载 Prop |

玩家直接右键或按槽位绑定键使用已发放的道具。自动触发由服务端根据配置执行。 [使用方式](/docs/prop/keybinds#三种使用方式)

## 绑定道具并发放

`/axs prop set` 需要玩家执行。手持要绑定的物品，填写 `props/` 下去掉扩展名的相对路径。比如定义在 `props/supplies/first_aid.yml` 时执行：

```text
/axs prop set supplies/first_aid
```

命令会给主手整叠物品写入道具 ID 和冷却标签。绑定好后即可把这叠物品发给玩家。再次执行 `set` 可以把手中物品改为另一种道具。道具定义中的 `name` 用于使用提示，物品原本的显示名可在物品来源中设置。

## 查看状态和重载

- 道具数用于确认文件加载结果，按键数用于确认客户端按键注册结果。
- 属性桥接状态会分别显示 AttributePlus、CraneAttribute、MythicLib、Symphony 和 Mod Attributes。用到某一种属性时核对对应一项。
- 重载会重新读取模块配置、按键、语言和道具定义，重新注册按键，并清除 Prop 仍在计时的临时属性。已绑定的物品按其道具 ID 使用重载后的定义。

## 权限

| 权限节点 | 默认 | 说明 |
|----------|------|------|
| `arcartxsuite.admin` | OP | 访问 `/axs prop` 管理命令 |
| `<道具定义中的 permission>` | 自定义 | 道具使用权限，在道具 YAML 的 `permission` 字段配置 |

道具的 `permission` 留空时，满足其他条件的玩家均可使用。填写权限后，手持、按键和自动触发都要求玩家拥有该权限。

插件接入时可使用[快捷道具接口](/docs/api/PropAccessible)查询道具 ID 和绑定目标玩家的主手物品。
