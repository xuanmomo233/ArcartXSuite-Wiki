| --- | --- |
| 提供模块 | [title](/docs/title) |
| 完整类型 | `xuanmo.arcartxsuite.api.capability.TitleConfigQueryable` |

## 获取接口

```java
import xuanmo.arcartxsuite.api.AxsCapabilities;
import xuanmo.arcartxsuite.api.capability.TitleConfigQueryable;

TitleConfigQueryable api = AxsCapabilities.get(TitleConfigQueryable.class);
if (api == null) return;
```

每次调用前获取接口。模块不可用时返回 `null`。 [调用约定](/docs/api/quick-start#调用约定)

## 方法声明

```java
public interface TitleConfigQueryable {

    @Nullable TitleInfo queryTitle(String titleId);

    record TitleInfo(String displayName, String qualityName, String description) {}
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `queryTitle` | 根据称号 ID 查询称号信息。 | `titleId`：称号 ID | 称号信息，未找到时返回 null |

## 调用注意事项

涉及 Bukkit 对象的操作在主线程执行。
