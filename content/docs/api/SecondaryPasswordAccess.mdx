## 获取接口

```java
import xuanmo.arcartxsuite.api.AxsCapabilities;
import xuanmo.arcartxsuite.api.capability.SecondaryPasswordAccess;

SecondaryPasswordAccess api = AxsCapabilities.get(SecondaryPasswordAccess.class);
if (api == null) return;
```

涉及玩家的调用在 Bukkit 主线程发起。

## 方法声明

```java
public interface SecondaryPasswordAccess {
    boolean isPasswordSet(@NotNull Player player);
    boolean isUnlocked(@NotNull Player player);
    CompletionStage<Status> statusAsync(@NotNull Player player);
    boolean verify(@NotNull Player player, @NotNull String password);
    CompletionStage<Boolean> verifyAsync(@NotNull Player player, @NotNull String password);
    boolean set(@NotNull Player player, @NotNull String oldPassword,
                @NotNull String newPassword);
    CompletionStage<Boolean> setAsync(@NotNull Player player, @NotNull String oldPassword,
                                     @NotNull String newPassword);
    boolean clear(@NotNull Player player, @NotNull String currentPassword);
    CompletionStage<Boolean> clearAsync(@NotNull Player player, @NotNull String currentPassword);
    int minLength();
    int maxLength();
    void lock(@NotNull Player player);
}
```

## 参数与返回值

| 方法 | 参数与作用 | 返回值 |
| --- | --- | --- |
| `isPasswordSet` | 目标玩家，检查是否已设置 | 是否已设置 |
| `isUnlocked` | 目标玩家，检查本次会话 | 是否已解锁 |
| `statusAsync` | 玩家，异步读取密码设置与本次会话的授权状态 | `CompletionStage<Status>` |
| `verify` | 玩家和输入的密码，验证成功后可解锁 | 验证结果 |
| `set` | 玩家、旧密码、新密码。更换已有密码时提供旧密码 | 是否设置成功 |
| `clear` | 玩家与当前密码，确认后清除 | 是否清除成功 |
| `verifyAsync` | 玩家和输入的密码，异步验证并尝试解锁当前会话 | 异步验证结果 |
| `setAsync` | 玩家、旧密码、新密码，异步设置或替换密码 | 异步设置结果 |
| `clearAsync` | 玩家与当前密码，异步清除密码 | 异步清除结果 |
| `minLength`、`maxLength` | 无参数，读取允许的长度 | 字符数 |
| `lock` | 玩家，请求重新锁定会话 | 无返回值 |

## 调用示例

在主线程提交查询。下面的 `plugin` 为调用方插件实例，`player` 为发起操作的玩家。

```java
UUID playerId = player.getUniqueId();
api.statusAsync(player).whenComplete((status, error) -> {
    if (!plugin.isEnabled()) return;
    Bukkit.getScheduler().runTask(plugin, () -> {
        if (!player.isOnline() || Bukkit.getPlayer(playerId) != player) return;
        if (error != null || status == null || !status.unlocked()) {
            player.sendMessage("请先解锁二级密码，再执行此操作。");
            return;
        }
        // 此处重新检查业务权限、请求及界面会话，再执行敏感操作。
    });
});
```

`Status.passwordSet()` 表示是否设置密码；`Status.unlocked()` 会复核会话、锁定和有效期，须在实际操作前调用，不能把先前的布尔结果当作长期凭证。业务必须设置密码时，还需检查 `status.passwordSet()`。

敏感操作经过排队或材料预留后，执行前调用原 `Status` 的 `revalidateAsync()`，异步确认存储中的密码状态仍与本次授权匹配。结果为 `true` 时切回主线程并再次检查 `unlocked()`，然后继续业务操作。结果为 `false` 或读取失败时请重新获取授权。

## 调用注意事项

界面收集输入后调用异步方法。回调操作 Bukkit 对象前切回主线程，并确认玩家仍是同一连接。同步查询和密码计算请避开频繁刷新的界面与定时器。

长度校验使用 `minLength()` 和 `maxLength()`。未设置密码时可按接口语义视为已授权；存储不可用、会话变化或状态无法确认时不应放行。获取接口的通用方式见[快速开始](/docs/api/quick-start)。
