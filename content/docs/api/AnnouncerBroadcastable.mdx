## 获取接口

```java
import xuanmo.arcartxsuite.api.AxsCapabilities;
import xuanmo.arcartxsuite.api.capability.AnnouncerBroadcastable;

AnnouncerBroadcastable api = AxsCapabilities.get(AnnouncerBroadcastable.class);
if (api == null) return;
```

每次调用前获取接口。模块不可用时返回 `null`。 [调用约定](/docs/api/quick-start#调用约定)

## 方法声明

```java
public interface AnnouncerBroadcastable {

    void broadcastNow(@NotNull String text);

    void broadcastNow(@NotNull String text, boolean forward);

    void enqueue(@NotNull String text, boolean forward);
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `broadcastNow` | 立即播报一条公告（强制打断当前展示，本服生效）。 | `text`：公告文本 | 无返回值 |
| `broadcastNow` | 立即播报一条公告。 | `text`：公告文本；`forward`：是否跨服转发到其他子服 | 无返回值 |
| `enqueue` | 将公告加入队列，当前展示结束后播报。 | `text`：公告文本；`forward`：是否跨服转发 | 无返回值 |

## 调用注意事项

涉及 Bukkit 对象的操作在主线程执行。
