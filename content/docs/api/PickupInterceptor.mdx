| 完整类型 | `xuanmo.arcartxsuite.api.capability.PickupInterceptor` |

## 获取接口

通过 `AxsCapabilities.get(PickupInterceptor.class)` 获取接口，按[调用约定](/docs/api/quick-start#调用约定)处理不可用结果。

## 方法声明

```java
public interface PickupInterceptor {

    boolean isAutoPickupIntercepted(@NotNull UUID playerId);
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `isAutoPickupIntercepted` | 查询该玩家的原版自动拾取是否已被本模块接管。 | `playerId`：玩家 UUID | `true` 表示拾取流程已被接管，其他模块不应自行处理拾取事件 |

## 调用注意事项

涉及 Bukkit 对象的操作在主线程执行。
