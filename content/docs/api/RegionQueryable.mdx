| 项目 | 说明 |
| --- | --- |
| 提供模块 | [regions](/docs/regions) |
| 完整类型 | `xuanmo.arcartxsuite.api.capability.RegionQueryable` |

## 获取接口

```java
import xuanmo.arcartxsuite.api.AxsCapabilities;
import xuanmo.arcartxsuite.api.capability.RegionQueryable;

var api = AxsCapabilities.get(RegionQueryable.class);
if (api != null) {
    var matches = api.regionsAt("world", 120, 65, -32);
}
```

在 Bukkit 主线程调用，并在业务操作时重新获取接口。模块不可用时返回 `null`。接入方式见[快速开始](/docs/api/quick-start)。

## 方法声明

```java
public interface RegionQueryable {
    List<RegionInfo> regionsAt(String world, int x, int y, int z);
    List<RegionInfo> regionsInWorld(String world);
    List<RegionInfo> allRegions();
    int countRegionsByOwner(UUID owner);

    record RegionInfo(
        String id, String world,
        int minX, int minY, int minZ,
        int maxX, int maxY, int maxZ,
        int priority, String parentId,
        Set<UUID> owners, Set<UUID> members
    ) {}
}
```

## 参数与返回值

| 方法 | 参数 | 返回值 |
| --- | --- | --- |
| `regionsAt` | 世界名和整数方块坐标 `x/y/z` | 命中的有界区域列表，按数值优先级降序排列 |
| `regionsInWorld` | 世界名 `world` | 此世界全部有界区域 |
| `allRegions` | 无 | 全部世界的有界区域 |
| `countRegionsByOwner` | 玩家 UUID `owner` | 玩家直接列在所有者中的区域数，权限组身份另行计算 |

`RegionInfo` 返回区域名、世界、包含边界的三维坐标、优先级、可空的父区 ID，以及直接列出的所有者和成员 UUID。权限组列表和旗标结果通过相应功能查询。

## 调用注意事项

几何命中与保护许可分别查询。需要检查玩家是否能执行某项操作时，使用[区域保护判定接口](/docs/api/RegionProtectionQueryable)获取合并规则和实际来源。

需要稳定 UUID 或绘制区域边界时，可使用 `RegionProtectionQueryable.boundaries`。每次查询后按当前业务使用结果，区域可能在管理员保存或重载后改变。
