## 获取接口

```java
import xuanmo.arcartxsuite.api.AxsCapabilities;
import xuanmo.arcartxsuite.api.capability.ChatMutable;

ChatMutable api = AxsCapabilities.get(ChatMutable.class);
if (api == null) return;
```

每次调用前获取接口。模块不可用时返回 `null`。 [调用约定](/docs/api/quick-start#调用约定)

## 方法声明

```java
public interface ChatMutable {

    @NotNull
    CompletionStage<String> mutePlayer(@NotNull String playerName, @Nullable Instant expiresAt, @Nullable String reason, @Nullable String mutedBy);

    @NotNull
    CompletionStage<String> unmutePlayer(@NotNull String playerName, @NotNull String operator);

    @NotNull CompletionStage<Boolean> isMuted(@NotNull UUID playerUuid);

    @NotNull
    CompletionStage<List<MuteInfo>> listMutes(int limit, int offset);

    record MuteInfo(
        @NotNull UUID playerUuid,
        @Nullable String playerName,
        @Nullable String mutedBy,
        @Nullable String reason,
        @Nullable Instant createdAt,
        @Nullable Instant expiresAt
    ) {
        public boolean isPermanent() { return expiresAt == null; }
    }
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `mutePlayer` | 禁言指定玩家。 | `playerName`：目标玩家名称；`expiresAt`：过期时间，null 表示永久禁言；`reason`：禁言原因，可为 null；`mutedBy`：执行者名称，可为 null | 异步返回操作结果消息（成功或失败原因） |
| `unmutePlayer` | 解除指定玩家的禁言。 | `playerName` 为目标玩家名称，`operator` 为执行者 | 异步返回操作结果消息（成功或失败原因） |
| `isMuted` | 从数据库查询玩家是否当前处于禁言状态 | `playerUuid`：目标玩家 UUID | 异步返回是否被禁言 |
| `listMutes` | 按玩家 UUID 分页查询生效禁言，包含离线玩家 | `limit`：1–100 条。 `offset`：从 0 开始的偏移量 | 异步返回禁言信息列表，到末页后返回空列表 |

## 调用注意事项

在主线程提交禁言和解禁。状态与列表异步读取，查询失败时异常完成。回调操作 Bukkit 对象前切回主线程。

`MuteInfo.isPermanent()` 判断是否永久禁言；离线玩家的名称可能为 `null`，展示列表时可使用 UUID。`listMutes` 查询持久化的有效记录，不应按在线玩家数量判断是否还有下一页。
