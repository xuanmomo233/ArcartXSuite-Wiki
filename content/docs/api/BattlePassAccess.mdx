## 获取接口

```java
import xuanmo.arcartxsuite.api.AxsCapabilities;
import xuanmo.arcartxsuite.api.capability.BattlePassAccess;

BattlePassAccess api = AxsCapabilities.get(BattlePassAccess.class);
if (api == null) return;
```

每次调用前获取接口。模块不可用时返回 `null`。 [调用约定](/docs/api/quick-start#调用约定)

## 方法声明

```java
public interface BattlePassAccess {

    boolean isSeasonActive();

    CompletionStage<Integer> addXp(@NotNull Player player, int xp);
    CompletionStage<Void> setXp(@NotNull Player player, int xp);
    CompletionStage<Void> removeXp(@NotNull Player player, int xp);
    CompletionStage<Void> setLevel(@NotNull Player player, int level);
    CompletionStage<Boolean> unlockTier(@NotNull Player player, @NotNull String tier);
    CompletionStage<Integer> claimAllRewards(@NotNull Player player);
    CompletionStage<Void> updateTaskProgress(@NotNull Player player, @NotNull String taskId, int increment);
    CompletionStage<Void> resetProgress(@NotNull UUID playerUuid);
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `isSeasonActive` | 当前赛季是否进行中。 | 无参数 | `true` 表示赛季正在进行 |
| `addXp` | 增加经验 | 玩家、增加量 | `CompletionStage<Integer>`，保存后的总经验 |
| `setXp` | 设置经验 | 玩家、目标经验 | `CompletionStage<Void>`，保存后完成 |
| `removeXp` | 扣减经验 | 玩家、扣减量 | `CompletionStage<Void>`，保存后完成 |
| `setLevel` | 设置等级 | 玩家、目标等级 | `CompletionStage<Void>`，保存后完成 |
| `unlockTier` | 解锁档位 | 玩家、`PREMIUM` 或 `DELUXE`，忽略大小写 | `CompletionStage<Boolean>`，是否成功 |
| `claimAllRewards` | 领取全部可领奖励 | 玩家 | `CompletionStage<Integer>`，已确认受理的奖励份数。实际到账以交付结果为准 |
| `updateTaskProgress` | 增加任务进度 | 玩家、任务 ID、增量 | `CompletionStage<Void>`，保存后完成 |
| `resetProgress` | 重置本赛季等级、经验、任务和领取记录 | 玩家 UUID | `CompletionStage<Void>`，保存后完成 |

## 调用示例

在主线程为 `player` 增加 100 点经验。`plugin` 为调用方的插件实例。回调若需更新界面，请切回主线程并核对玩家连接。

```java
api.addXp(player, 100).whenComplete((totalXp, error) -> {
    if (error != null) {
        plugin.getLogger().warning("战令经验写入未确认: " + error.getMessage());
        return;
    }
    plugin.getLogger().info("保存后的战令经验: " + totalXp);
});
```

## 调用注意事项

写操作异步完成。同一玩家的请求按提交顺序处理。取消等待或超时后，请核对实际结果再决定是否重试增减经验。`claimAllRewards` 异常完成时，部分奖励可能已受理，按原领取状态核对。
