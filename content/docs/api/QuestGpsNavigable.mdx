## 获取接口

通过 `AxsCapabilities.get(QuestGpsNavigable.class)` 获取接口，按[调用约定](/docs/api/quick-start#调用约定)处理不可用结果。

## 方法声明

```java
public interface QuestGpsNavigable {

    enum QuestState {

        NONE,

        ACTIVE,

        COMPLETED
    }

    void offerQuest(@NotNull Player player, @NotNull String questId, boolean openMenu);

    default boolean tryOfferQuest(@NotNull Player player, @NotNull String questId, boolean openMenu) {
        return false;
    }

    void acceptQuest(@NotNull Player player, @NotNull String questId);

    void openMenu(@NotNull Player player);

    void trackQuest(@NotNull Player player, @NotNull String questId);

    void trackTask(@NotNull Player player, @NotNull String questId, @NotNull String taskId);

    boolean eventRuleLocked(@NotNull Player player, @NotNull String ruleId);

    boolean moduleEntryLocked(@NotNull Player player, @NotNull String moduleEntryId);

    @NotNull QuestState questState(@NotNull Player player, @NotNull String questId);
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `offerQuest` | 向玩家推送任务供选择 | `player`：目标玩家（`Player`）；`questId`：任务 ID（`String`）；`openMenu` 为 true 时同时打开任务菜单（`boolean`） | 无返回值 |
| `tryOfferQuest` | 检查权限、分类、主线前置及任务状态，再推荐可接取的任务 | `player` 为目标玩家，`questId` 为任务 ID，`openMenu` 控制是否打开任务菜单 | `true` 表示已触发推荐，`false` 表示当前无法推荐 |
| `acceptQuest` | 让玩家接受任务 | `player`：目标玩家（`Player`）；`questId`：任务 ID（`String`） | 无返回值 |
| `openMenu` | 打开任务菜单 | `player`：目标玩家（`Player`） | 无返回值 |
| `trackQuest` | 追踪任务 | `player`：目标玩家（`Player`）；`questId`：任务 ID（`String`） | 无返回值 |
| `trackTask` | 追踪任务的指定步骤 | `player`：目标玩家（`Player`）；`questId`：任务 ID（`String`）；`taskId`：任务 ID（`String`） | 无返回值 |
| `eventRuleLocked` | 检查事件规则是否被主线门禁锁定 | `player`：目标玩家（`Player`）；`ruleId`：对应条目的 ID（`String`） | `true` 表示事件规则仍被锁定 |
| `moduleEntryLocked` | 检查其他模块入口是否被主线门禁锁定 | `player`：目标玩家（`Player`）；`moduleEntryId`：对应条目的 ID（`String`） | `true` 表示模块入口仍被锁定 |
| `questState` | 查询玩家某任务的 Chemdah 档案状态。 questId 与 `#acceptQuest` 同语义（questgps 配置/别名可解析的 id）。 档案未加载或从未接取返回 `QuestState#NONE`。 | `player`：目标玩家（`Player`）；`questId`：任务 ID（`String`） | `QuestState` 任务状态。档案未加载或从未接取时为 NONE |

## 调用注意事项

涉及 Bukkit 对象的操作在主线程执行。
