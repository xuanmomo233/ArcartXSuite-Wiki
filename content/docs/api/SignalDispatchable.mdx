| 提供模块 | [eventpacket](/docs/eventpacket) |
| 完整类型 | `xuanmo.arcartxsuite.api.capability.SignalDispatchable` |

## 获取接口

通过 `AxsCapabilities.get(SignalDispatchable.class)` 获取接口，按[调用约定](/docs/api/quick-start#调用约定)处理不可用结果。

## 方法声明

```java
public interface SignalDispatchable {

    void dispatchSignal(@NotNull String signal, @NotNull Player subject, @Nullable Map<String, String> variables);
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `dispatchSignal` | 向指定玩家触发一个信号，由 EventPacket 规则引擎匹配并执行对应动作。 | `signal`：信号名称（如 `"signin_success"`）；`subject`：触发玩家；`variables`：附加变量（可为空） | 无返回值 |

## 调用注意事项

涉及 Bukkit 对象的操作在主线程执行。
