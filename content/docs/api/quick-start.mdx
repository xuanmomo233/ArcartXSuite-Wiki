## 准备依赖

将与目标 Suite 发行版配套的 `axs-api` JAR 保存为项目中的 `libs/axs-api.jar`。使用 `compileOnly`，运行时由游戏服中的 Suite 提供这些类。

在使用 Gradle 的插件项目中，将以下内容写入 `build.gradle.kts`。Bukkit API 依赖和 Java 工具链按目标游戏服选择，下方为一组编译示例。

```kotlin
plugins {
    java
}

repositories {
    mavenCentral()
    maven("https://hub.spigotmc.org/nexus/content/repositories/snapshots/")
}

dependencies {
    compileOnly(files("libs/axs-api.jar"))
    compileOnly("org.spigotmc:spigot-api:1.20.1-R0.1-SNAPSHOT")
    compileOnly("org.jetbrains:annotations:24.1.0")
}

java {
    toolchain.languageVersion.set(JavaLanguageVersion.of(17))
}
```

使用更高版本的服务端时，按需替换 Bukkit API 坐标，并核对插件的 Java 目标版本与服务器 JVM 兼容。

## 声明插件依赖

在 `src/main/resources/plugin.yml` 声明依赖。插件名取自 Suite 随包的 `plugin.yml`，这里是 `ArcartX-Suite`。

```yaml
name: SuiteBridgeExample
version: 1.0.0
main: example.SuiteBridgeExample
api-version: '1.20'
depend: [ArcartX-Suite]
commands:
  servermenu:
    description: 打开服务器菜单
    permission: suitebridge.menu
permissions:
  suitebridge.menu:
    default: true
```

## 完整最小示例

将类保存为 `src/main/java/example/SuiteBridgeExample.java`。它调用 Menu 打开 `id: trial_menu` 的测试菜单。

```java
package example;

import java.util.Objects;
import org.bukkit.entity.Player;
import org.bukkit.plugin.java.JavaPlugin;
import xuanmo.arcartxsuite.api.AxsCapabilities;
import xuanmo.arcartxsuite.api.capability.MenuOpenable;

public final class SuiteBridgeExample extends JavaPlugin {
    @Override
    public void onEnable() {
        Objects.requireNonNull(getCommand("servermenu")).setExecutor(
            (sender, command, label, args) -> {
                if (!(sender instanceof Player player)) {
                    sender.sendMessage("请在游戏中使用此命令。");
                    return true;
                }
                MenuOpenable menu = AxsCapabilities.get(MenuOpenable.class);
                if (menu == null) {
                    player.sendMessage("菜单功能暂不可用。");
                    return true;
                }
                if (!menu.openMenu(player, "trial_menu")) {
                    player.sendMessage("菜单未能打开，请联系管理员检查配置。");
                }
                return true;
            });
    }
}
```

## 游戏内验证

1. 按[菜单最小示例](/docs/menu/configuration#从一个可验证的按钮开始)创建 `trial_menu` 并启用 Menu。
2. 用 Gradle 执行 `build`，将 `build/libs/` 中的桥接插件 JAR 放入游戏服 `plugins/` 后重启。
3. 用 ArcartX 客户端和具有 `suitebridge.menu` 的测试玩家执行 `/servermenu`，应打开「试炼入口」。菜单定义另有打开权限或条件时，玩家也须满足。
4. 在测试服停用 Menu 后执行同一命令，应收到「菜单功能暂不可用」。模块重新启用后再次执行，应重新打开菜单。

## 可选接入

需要兼容缺少 Suite 的服务器时，在 `plugin.yml` 使用 `softdepend`。把 Suite 类型引用放在独立类中，确认 `ArcartX-Suite` 已启用后再加载该类。

## 调用约定

- 每次业务操作通过 `AxsCapabilities.get(接口.class)` 获取能力。本体未就绪、模块未启用或该功能尚未注册时，结果为 `null`。注册长期回调时，另外保留注销需要的句柄或订阅 ID。
- 只复制方法体的片段放在自己的方法里，导入所用类型。`player` 为在线 `Player`，`plugin` 为调用方的 `JavaPlugin`。
- 在 Bukkit 主线程发起使用玩家、物品或容器的调用。异步方法用回调处理结果与异常；回到主线程操作玩家前，确认仍是原连接。
- 使用目标模块配置中的实际 ID。根据对应接口的返回值判断状态和结果。
