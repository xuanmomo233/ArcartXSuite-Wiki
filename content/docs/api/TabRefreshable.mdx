title: "在线列表刷新接口"
description: "向 Velocity 重新上报子服玩家的准入与隐身状态。"
---

| 项目 | 说明 |
| --- | --- |
| 提供模块 | [tab](/docs/tab) |
| 完整类型 | `xuanmo.arcartxsuite.api.capability.TabRefreshable` |

子服 Tab 启用 `settings.proxy-roster` 后，此接口可刷新向 Velocity 上报的可见状态。

## 获取接口

通过 `AxsCapabilities.get(TabRefreshable.class)` 获取接口，按[调用约定](/docs/api/quick-start#调用约定)处理不可用结果。

## 方法声明

```java
public interface TabRefreshable {

    @NotNull CompletionStage<Boolean> requestVanish(@NotNull Player player);
    void requestViewerRefresh(@NotNull Player viewer, @Nullable String reason);

    void requestGlobalRefresh(@Nullable String reason);
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `requestVanish` | 向代理申请开启隐身 | 在线玩家 | `CompletionStage<Boolean>`，`true` 才可启用隐身 |
| `requestViewerRefresh` | 重新检查指定玩家的准入与隐身状态，变化时向代理上报。 | `viewer`：要上报状态的玩家，`reason` 可传 `null` | 无返回值 |
| `requestGlobalRefresh` | 检查本服在线玩家的状态，向代理上报有变化的玩家。 | `reason` 可传 `null` | 无返回值 |

## 调用注意事项

在 Bukkit 主线程调用 `requestVanish`。回调在服务器线程执行。收到 `true` 后，确认原连接和权限仍有效，再开启隐身并请求刷新。 [付费客户水印版跨服名单配置](/docs/tab/cross-server)
