| 项目 | 说明 |
| --- | --- |
| 提供模块 | [prop](/docs/prop) |
| 完整类型 | `xuanmo.arcartxsuite.api.capability.PropAccessible` |

## 获取接口

通过 `AxsCapabilities.get(PropAccessible.class)` 获取接口，按[调用约定](/docs/api/quick-start#调用约定)处理不可用结果。

## 方法声明

```java
public interface PropAccessible {

    @NotNull List<String> propIds();

    @NotNull PropApplyResult applyPropToMainHand(@NotNull Player player, @NotNull String propId);

    record PropApplyResult(boolean success, @NotNull String message) {}
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `propIds` | 查询已加载的道具 ID | 无参数 | `List<String>` |
| `applyPropToMainHand` | 将目标玩家主手的整叠物品绑定为该道具 | 目标 `player` 和道具 `propId` | `PropApplyResult` 包含成功状态与提示 |

## 绑定物品

下例要求玩家主手持有物品，并且 Prop 已加载 `props/field_ration.yml`。

```java
var result = api.applyPropToMainHand(player, "field_ration");
player.sendMessage(result.message());
if (!result.success()) {
    return;
}
// 主手物品已绑定，可继续发放流程。
```

## 调用注意事项

在 Bukkit 主线程查询和绑定。使用方式由道具配置决定。监听实际使用时订阅 `axs.prop.prop_used`。 [事件字段](/docs/prop/effects#使用事件联动)
