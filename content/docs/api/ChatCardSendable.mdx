| 项目 | 说明 |
| --- | --- |
| 提供模块 | [chat](/docs/chat) |
| 完整类型 | `xuanmo.arcartxsuite.api.capability.ChatCardSendable` |

## 获取接口

通过 `AxsCapabilities.get(ChatCardSendable.class)` 获取接口，按[调用约定](/docs/api/quick-start#调用约定)处理不可用结果。

## 方法声明

```java
public interface ChatCardSendable {

    boolean sendChatCard(@NotNull Player player, @NotNull String cardId, @NotNull Map<String, String> data);
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `sendChatCard` | 向指定玩家发送聊天卡片。 | `player`：目标玩家；`cardId`：卡片 id；`data`：附加数据 | `true` 表示发送成功 |

## 调用注意事项

涉及 Bukkit 对象的操作在主线程执行。
