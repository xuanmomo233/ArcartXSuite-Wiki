| 项目 | 说明 |

| 提供模块 | [qqbot](/docs/qqbot) |
| 完整类型 | `xuanmo.arcartxsuite.api.capability.QQBotNotifiable` |

## 获取接口

通过 `AxsCapabilities.get(QQBotNotifiable.class)` 获取接口，按[调用约定](/docs/api/quick-start#调用约定)处理不可用结果。

## 方法声明

```java
public interface QQBotNotifiable {

    void registerListener(@NotNull QQGroupEventListener listener);

    void unregisterListener(@NotNull QQGroupEventListener listener);

    interface QQGroupEventListener {

        void onGroupMessage(long groupId, long senderId, @NotNull String nickname, @NotNull String message) ;

        void onMemberJoin(long groupId, long userId) ;

        void onMemberLeave(long groupId, long userId) ;
    }
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `registerListener` | 注册一个群事件监听器。 | `listener`：监听器实例 | 无返回值 |
| `unregisterListener` | 注销一个群事件监听器。 | `listener`：监听器实例 | 无返回值 |

## 调用注意事项

群消息、入群和退群事件独立于聊天同步开关。回调在 QQBot 线程执行，操作 Bukkit 对象前切回主线程。重载后重新获取接口并注册；注销前已开始的回调会继续完成。

涉及 Bukkit 对象的操作在主线程执行。
