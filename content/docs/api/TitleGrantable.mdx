| 项目 | 说明 |
| --- | --- |
| 提供模块 | [title](/docs/title) |
| 完整类型 | `xuanmo.arcartxsuite.api.capability.TitleGrantable` |

## 获取接口

```java
import xuanmo.arcartxsuite.api.AxsCapabilities;
import xuanmo.arcartxsuite.api.capability.TitleGrantable;

TitleGrantable api = AxsCapabilities.get(TitleGrantable.class);
if (api == null) return;
```

每次调用前获取接口。模块不可用时返回 `null`。 [调用约定](/docs/api/quick-start#调用约定)

## 方法声明

```java
public interface TitleGrantable {

    boolean giveTitle(@NotNull UUID playerId, @NotNull String titleId, @NotNull String duration, @NotNull String source);
    CompletableFuture<Boolean> grantPermanent(@NotNull UUID playerId, @NotNull String titleId, @NotNull String source);
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `giveTitle` | 授予称号 | 玩家 UUID、称号 ID、时长（如 `permanent`、`7d`）、来源标识 | `true` 表示授予成功 |
| `grantPermanent` | 异步授予永久称号 | 玩家 UUID、称号 ID、来源标识 | `CompletableFuture<Boolean>`，保存成功时返回 `true` |

## 调用注意事项

涉及 Bukkit 对象的操作在主线程执行。
