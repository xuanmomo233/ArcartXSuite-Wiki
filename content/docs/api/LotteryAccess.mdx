## 获取接口

```java
import xuanmo.arcartxsuite.api.AxsCapabilities;
import xuanmo.arcartxsuite.api.capability.LotteryAccess;

LotteryAccess api = AxsCapabilities.get(LotteryAccess.class);
if (api == null) {
    // 当前功能不可用，向玩家说明或使用你的替代流程。
    return;
}
```

每次业务操作时重新获取接口；模块未加载或暂时不可用时返回 `null`。接入方式见[快速开始](/docs/api/quick-start)。

## 方法声明

```java
public interface LotteryAccess {

    @NotNull CompletionStage<Long> getPoint(@NotNull UUID playerUuid, @NotNull String pointId);

    @NotNull CompletionStage<Map<String, Long>> getPoints(@NotNull UUID playerUuid);

    @NotNull CompletionStage<Boolean> givePoints(@NotNull UUID playerUuid, @NotNull String pointId, long amount);

    @NotNull CompletionStage<Boolean> exchange(@NotNull Player player, @NotNull String itemId);

    @NotNull CompletionStage<List<CaseDrawResult>> openCase(@NotNull Player player, @NotNull String poolId, int count);

    record CaseDrawResult(
        @NotNull String rarity,
        int poolIndex,
        @Nullable String itemKey,
        @Nullable String itemName,
        int amount
    ) {}
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `getPoint` | 查询玩家指定积分余额。 | `playerUuid`：玩家 UUID；`pointId`：积分 ID | 异步返回余额，未设置时为 0 |
| `getPoints` | 查询玩家全部积分余额 | `playerUuid` 为玩家 UUID | 异步返回以积分 ID 为键的余额映射 |
| `givePoints` | 为玩家增加抽奖积分。 | `playerUuid`：玩家 UUID；`pointId`：积分 ID；`amount`：增加数量 | 异步返回写入是否成功 |
| `exchange` | 为玩家执行一次兑换商店兑换。 | `player`：在线玩家；`itemId`：兑换条目 ID | 异步返回兑换和奖励确认结果 |
| `openCase` | 为玩家批量开启 CASE 奖池。 | `player`：在线玩家；`poolId`：奖池 ID；`count`：1–10 次 | 异步返回本次确认的开箱结果 |

## 调用注意事项

这些操作返回 `java.util.concurrent.CompletionStage`。在 Bukkit 主线程提交兑换和开箱。结果可能在后台线程完成，回调要操作玩家或 UI 时先切回主线程。主线程不能用 `join()` 或 `get()` 等待结果。

兑换或发奖未确认时，先核对操作记录和实际交付状态，再决定是否重试。
