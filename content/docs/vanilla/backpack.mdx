在 `plugins/ArcartX-Suite/data/vanilla/config.yml` 中启用随身背包，执行 `/axs reload vanilla` 后，玩家可用 `/axs vanilla backpack` 打开界面。

```yaml
backpack:
  enabled: true
  ui:
    register-ui-on-enable: true
    overwrite-ui-files: false
```

| 字段 | 说明 |
| --- | --- |
| `backpack.enabled` | 开启随身背包，默认关闭 |
| `backpack.ui.register-ui-on-enable` | 启用时注册背包界面 |
| `backpack.ui.overwrite-ui-files` | 重载时用内置模板覆盖 `ui/vanilla/vanilla_backpack.yml` |

Warehouse 为可选模块。没有 Warehouse 时，随身背包仍可使用玩家背包、装备栏、整理功能和随身工作台；启用 Warehouse 后显示个人仓库区域。

## 顶栏操作

| 按钮 | 操作 |
| --- | --- |
| 整理背包 | 合并并排列玩家背包的 27 个储物栏格子，快捷栏、装备和副手保留原位 |
| 合成 | 打开随身 3×3 工作台，使用当前服务端已注册的可用配方 |
| 设置 | 查看个人仓库容量，并在配置了槽位价格时购买容量 |
| 关闭 | 关闭随身背包 |

“整理背包”需要 `arcartxsuite.vanilla.sort`。拿着光标物品、正在处理库存操作或确认操作时，先完成当前操作再整理。

整理会按完整物品数据合并堆叠，并遵守物品的堆叠上限。排序规则由 `inventory-sort.mode` 设置，见[功能配置](/docs/vanilla/configuration#背包与箱柜整理)。

## MMOItems 饰品属性

启用随身背包，并在服务端安装 MMOItems 和 MythicLib，就可以让指定的 ArcartX 饰品槽参与 MMOItems 的装备属性结算。在 `plugins/ArcartX-Suite/data/vanilla/config.yml` 的现有 `backpack` 节中加入槽位名单，修改后执行 `/axs reload vanilla`。

```yaml
backpack:
  # 默认 []，留空关闭。下方 ID 是西方中世纪背包的示例。
  mmoitems-attribute-slots: [accessory_1, accessory_2, accessory_3]
```

填写 ArcartX 额外槽位的实际 ID，区分大小写。名单内的物品仍须满足 MMOItems 的饰品类型和装备要求。穿戴或取下物品时，MMOItems 会重新计算玩家属性。只将饰品槽加入名单，药水槽和仓库槽用于各自的功能。

## 转场与角色动作

这项功能默认关闭。在 `plugins/ArcartX-Suite/data/vanilla/config.yml` 的现有 `backpack` 节下加入 `presentation`，开启后执行 `/axs reload vanilla`。只想使用面板和镜头转场时，可以将动作名全部留空。

```yaml
backpack:
  presentation:
    enabled: true          # 开启背包转场和已配置的角色动作
    transition-ms: 220     # 面板和镜头的转场时长（毫秒），0 关闭转场
    blend-ms: 100          # 动作混合时长（毫秒），0 直接切换
    open:
      animation: ''        # 入场动作名，留空跳过
      duration-ms: 450     # 入场动作播放时长（毫秒）
    idle:
      animation: ''        # 循环待机动作名，留空沿用普通待机
    random:
      min-interval-ms: 6000   # 待机后到下次随机动作的最短等待（毫秒）
      max-interval-ms: 12000  # 最长等待（毫秒），小于最短等待时按最短等待计算
      actions: {}            # 动作池，留空跳过随机播放
```

为 `random.actions` 添加动作时，用下方结构替换 `actions: {}`。条目的键名由服主自定，每项填写动作名、播放时长和权重。

```yaml
actions:
  示例条目:
    animation: ''        # 动作名，留空忽略该项
    duration-ms: 650     # 播放时长（毫秒），默认 650
    weight: 1            # 相对抽取权重，默认 1，0 忽略该项
```

打开背包时播放一次入场动作，再进入待机并开始随机动作计时。随机动作结束后回到待机，有其他可选动作时避免连续重复。动作仅对开包玩家显示，关闭背包后结束。

动作名与客户端动作包完全一致。待机动作设为循环，入场和随机动作填写实际时长。自定义 `ui/vanilla/vanilla_backpack.yml` 时保留转场初始化、控件表达式和 `var.backpackTransitionMs`。

## 个人仓库存取

仓库区域与 Warehouse 的个人仓库共用物品、容量和二级密码。

| 操作 | 效果 |
| --- | --- |
| 左键仓库物品 | 取出至多一组到玩家背包 |
| 右键仓库物品 | 取出半组到玩家背包 |
| 拿着物品点击存入区 | 将光标物品存入个人仓库，同类物品自动合并。未存入的余量放回背包 |
| 搜索、分类、排序与翻页 | 查找仓库条目 |
| 默认排序下点击星标 | 置顶或取消置顶 |

条目图标旁显示仓库总数量，取出后自动补足显示。同类物品按完整数据合并，仓库总量可超过普通堆叠上限。

背包须能放下本次取出的数量或存入后剩余的物品。空间不足时，先腾出空间再操作。收到凭证待核对提示时，按[仓库存取恢复](/docs/warehouse/material-recovery#仓库存取中断后的恢复)查询原服记录。

分类、排序和置顶使用 [Warehouse 的分类与搜索配置](/docs/warehouse/categories)。仓库排序调整仓库条目的显示顺序；顶栏“整理背包”整理玩家的 27 格储物栏。

## 管理容量

在 Warehouse 的 `warehouses.personal` 中设置 `base-slots`、`max-slots` 和 `slot-price`。当前容量为基础格数加已购格数，并受上限限制。

| 命令 | 操作 |
| --- | --- |
| `/axs vanilla backpack status` | 查看背包状态 |
| `/axs vanilla backpack info <玩家>` | 查看玩家个人仓库概况 |
| `/axs vanilla backpack give Steve materials 9` | 为玩家增加 9 格共用容量 |
| `/axs vanilla backpack reset Steve materials` | 将玩家已购容量重置为 0 |

容量管理命令需要 `arcartxsuite.vanilla.backpack.admin`。分类不会形成独立的容量预算。

## 消息配置

随身背包与容器界面的操作提示共用 `data/vanilla/message.yml`。修改文本后执行 `/axs reload vanilla`。
