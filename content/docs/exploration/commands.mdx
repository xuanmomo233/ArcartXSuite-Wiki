## 玩家操作

1. 走进探索区域，按 HUD 显示的按键并保持原位。
2. 读条结束后，按结果提示继续。如果发现场景中的宝箱，右键打开战利品界面，然后点击 **领取全部**。

玩家可以在 ArcartX 按键设置里改绑 `AXS_EXPLORE`。QuestGPS 推荐任务仍使用其自己的玩家权限，Abyss 秘境仍检查副本准入条件。

## 管理员命令

| 命令 | 用途 |
| --- | --- |
| `/axs status` | 查看 Exploration 是否已加载。 |
| `/axs reload exploration` | 重读模块配置和已导出的 HUD、宝箱 UI，并清理正在探索的会话及未领取的宝箱。 |

以上命令需要 `arcartxsuite.admin`。控制台执行时省略斜杠。调整按键后，在线玩家可在 ArcartX 按键设置检查 `AXS_EXPLORE` 当前绑定，未同步时重连一次。

## HUD 与结果排查

| 现象 | 先检查什么 |
| --- | --- |
| 进区域没有提示 | 世界名、两角的 Y 坐标、区域是否启用，以及玩家在该区域是否仍处于冷却。退出容器界面后再试。 |
| 提示出现，按键后没有读条 | 确认客户端当前绑定和按键冲突，原地测试。模块更新后重连再试。 |
| 读条完成但结果不可用 | 先只保留采集，再按[目标核对表](/docs/exploration/configuration#加入任务和奇遇)逐项检查宝箱资源或联动模块。 |
