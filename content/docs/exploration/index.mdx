| 界面文件 | `plugins/ArcartX-Suite/ui/exploration/` 下的 `exploration_hud.yml` 与 `exploration_chest.yml` |
| 重载 | `/axs reload exploration` |
| 客户端按键 | `AXS_EXPLORE`，默认 V，玩家可在 ArcartX 按键设置中改绑 |

## 第一次使用

1. 启用 Exploration，用 `/axs status` 确认模块已加载。测试玩家使用与服务端匹配的 ArcartX 客户端。
2. 按[配置示例](/docs/exploration/configuration#配置示例)建立一个单独的测试区域。记下游戏服的世界名和区域两个对角方块坐标，用它们替换示例里的 `world`、`corner-a` 和 `corner-b`。
3. 执行 `/axs reload exploration`。使用一个已经准入的普通玩家，关闭背包或容器界面，走进测试区域。第一次只启用原版物品采集。

## 检查是否配置成功

进区域后应出现按键提示。先试一次走动中断，再站定读满，检查背包增加 3 个甜浆果。验收后按需启用[个人宝箱](/docs/exploration/configuration#配置宝箱模型)和[联动奇遇](/docs/exploration/configuration#加入任务和奇遇)。
