Essentials 传送系统提供家（home）、传送点（warp）、出生点（spawn）、玩家间传送请求（TPA）、`/back` 返回、延迟传送与安全传送。

## 家（Home）

每个玩家可设置多个家，数量受 `teleport.max-homes` 限制（默认 3）。

- `/sethome <名称>` 设置或更新家（超出上限提示）
- `/delhome <名称>` 删除家
- `/home <名称>` 传送到家
- 家名称不区分大小写，同名家被覆盖

### 权限覆盖上限

通过 `axs.essentials.homes.<数字>` 权限节点可覆盖 `max-homes`，取玩家拥有的最高值作为实际上限。

> 例如配置 `max-homes: 3`，玩家拥有 `axs.essentials.homes.10` 权限时上限提升为 10。仅对新增家生效，更新已有家不检查上限。

## 传送点（Warp）

传送点是全服共享的公共传送点：

- 使用需要 `axs.essentials.warp` 权限
- `/setwarp`、`/delwarp` 分别需要 `axs.essentials.setwarp` / `axs.essentials.delwarp` 权限
- 传送点名称不区分大小写，同名被覆盖

## 出生点（Spawn）

`/setspawn` 以管理员当前位置设置服务器出生点；`/spawn` 传送到出生点，未设置时传送到世界默认出生点。

## TPA 请求

| 命令 | 传送方向 |
|------|----------|
| `/tpa <玩家>` | 请求者传送到目标 |
| `/tpahere <玩家>` | 目标传送到请求者 |

- `/tpaccept [玩家]` 接受请求并执行延迟传送，`/tpdeny [玩家]` 拒绝并通知双方。存在多个请求时要指定发送者
- `/tptoggle` 切换是否接收请求，设置会保存。`/tpcancel [玩家]` 撤回指定请求，省略玩家名时撤回自己发出的全部请求
- 请求在 `tpa-timeout`（默认 60 秒）后过期并通知发送者
- 同一发送者和接收者之间保留一条请求。不同玩家的请求分别保存，受配置中的收发上限和冷却限制。任一方下线会清理对应请求

## 延迟传送与预热

除 `/tp` 外，所有传送命令默认经过预热（`teleport.teleport-delay`，默认 3 秒）：

| 条件 | 行为 |
|------|------|
| `teleport-delay <= 0` | 即时传送 |
| 拥有 `axs.essentials.teleport.bypass-delay` | 跳过预热，即时传送 |
| 预热期间移动 | 取消传送并提示（`cancel-on-move: false` 时禁用移动取消） |

## 安全传送

`teleport.safe-teleport: true` 时，目标需在世界边界内，脚下有可站立的方块，身体所在位置须可通行且避开危险方块。目标点不可用时会在同一列上下各找最多 8 格。找不到安全位置时取消传送。

## 返回栈（/back）

传送成功后记录出发位置，`/back` 返回最近的记录。预热取消或返回失败时保留该记录。栈深度由 `teleport.back-stack-size`（默认 5）控制，连续传送可多级返回。

## 直接传送

| 命令 | 功能 |
|------|------|
| `/top` | 传送到当前坐标最高方块上方（走预热） |
| `/tp <玩家> [目标]` | 传送到玩家，或传送玩家到目标（即时传送，不走预热） |
| `/tppos <x> <y> <z>` | 传送到指定坐标（走预热） |

## UI 菜单

玩家工具菜单（`/ess menu`）提供家列表、传送点、TPA 页面；管理员面板（`/ess admin`）提供传送到玩家/传送玩家到自己、设置传送点与出生点等操作。

TPA 页点「待处理」可查看请求人、方向和剩余秒数，也可逐条接受或拒绝。点「刷新」更新剩余时间。传送点页支持按名称或分组搜索和筛选已收藏的点。

`/ess warps [关键词或 favorites] [页码]` 可搜索传送点。`/ess warpfavorite <传送点>` 切换个人收藏。创建和修改方法见[基础工具配置](/docs/essentials/configuration)。

传送点统一保存在 `config.yml` 的 `warps` 节。`/setwarp` 保存当前位置，`/delwarp` 删除指定点，保存后立即生效。

### 卡点脱困

`/ess unstuck` 会寻找附近已加载区块里的安全落脚点，需要 `axs.essentials.unstuck`。预热期间移动会取消，战斗冷却、禁止世界、Regions 边界和 Abyss 副本状态也会限制脱困。

## 配置项汇总

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `teleport.tpa-timeout` | `60` | TPA 请求过期时间（秒，最小 10） |
| `teleport.teleport-delay` | `3` | 传送预热延迟（秒，0=即时） |
| `teleport.cancel-on-move` | `true` | 预热期间移动是否取消 |
| `teleport.max-homes` | `3` | 每玩家家数量上限（可被权限覆盖） |
| `teleport.back-stack-size` | `5` | `/back` 返回栈最大深度 |
| `teleport.safe-teleport` | `true` | 是否启用安全传送 |
