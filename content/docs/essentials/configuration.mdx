## 配置文件概览

Essentials 模块使用两个配置文件：

| 文件 | 说明 | 重载命令 |
|------|------|----------|
| `config.yml` | 主配置文件，包含全部功能开关与参数 | `/axs reload essentials` |
| `messages.yml` | 消息模板文件，包含命令提示与错误消息 | `/axs reload essentials` |

配置文件位于 `plugins/ArcartX-Suite/data/essentials/`。首次启动时自动导出默认配置。

### 顶层字段

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `config-version` | `int` | `3` | 配置版本号，使用自动生成的值 |
| `debug` | `boolean` | `false` | 是否输出调试日志 |
| `command-conflict-protection` | `boolean` | `false` | 同名时是否保留已有的无前缀命令 |
| `command-aliases` | `map<string, string>` | 见下文 | 命令简写别名映射（别名 → action） |
| `disabled-actions` | `list<string>` | `[]` | 停用的子命令名。对应的面板操作和顶层简写也会停用 |
| `warps` | `map` | `{}` | 从 YAML 新建、修改、分组或停用的传送点 |

### 命令冲突保护

```yaml
command-conflict-protection: false
```

- `false` 时，遇到原版或其他插件的同名命令，`/tp` 等无前缀命令优先使用 Essentials 简写。原命令仍可用原有前缀调用，例如 `/minecraft:tp`。
- `true` 时，保留已有的无前缀命令。遇到同名冲突时，用 `/arcartx-suite:tp` 等带前缀的命令调用 Essentials 简写。

修改后执行 `/axs reload essentials`。注册日志会标明发生冲突的命令来源。

### 停用功能

例如 `disabled-actions: [sudo, inv, weather]` 会停用强制执行、背包查看和天气管理。`tpa.enabled: false` 可关闭整套传送请求，`unstuck.enabled: false` 可关闭脱困。已经生效的封禁仍会在登录时检查。

### 在 YAML 新建或修改 Warp

将 `warps: {}` 替换成以下结构，并按地图填写世界名和坐标。

```yaml
warps:
  hub:
    world: world
    x: 100.5
    y: 70
    z: -20.5
    yaw: 90
    pitch: 0
    group: 主城
    permission: ""
    enabled: true
  event-gate:
    enabled: false
```

- 启用的点需要 `world`、`x`、`y`、`z`。`yaw` 和 `pitch` 默认是 0。`group` 默认是「默认」。
- `permission` 留空时，拥有基础 Warp 权限的玩家可见。填写权限节点后，列表和实际传送都会检查该权限。
- 传送点名称大小写视为相同，名称不能包含句点。用 `enabled: false` 可停用该点。
- `/setwarp <名称>` 把当前位置写入 `config.yml`，更新已有点时保留分组、权限和启用状态。`/delwarp <名称>` 删除相应配置。两条命令保存后立即生效。

手动修改后执行 `/axs reload essentials`，用 `/ess warps` 查看列表。玩家菜单可按名称或分组搜索，也可切换收藏视图。

### 请求与脱困设置

| 字段 | 默认 | 说明 |
|---|---|---|
| `tpa.enabled` | `true` | 启用传送请求 |
| `tpa.cooldown-seconds` | `5` | 发出请求间隔，0 表示无间隔 |
| `tpa.max-incoming` / `tpa.max-outgoing` | `5` / `5` | 同时待处理的接收和发出上限 |
| `unstuck.enabled` | `true` | 启用脱困 |
| `unstuck.cooldown-seconds` | `120` | 成功脱困后的冷却 |
| `unstuck.warmup-seconds` | `3` | 脱困预热，移动会取消 |
| `unstuck.combat-seconds` | `15` | 最近受到伤害或造成攻击伤害后的等待时间 |
| `unstuck.search-radius` / `unstuck.vertical-range` | `4` / `4` | 水平和垂直搜索距离 |
| `unstuck.only-when-stuck` | `true` | 仅在站立点不安全或周围没有可行走出口时允许 |
| `unstuck.allowed-worlds` / `unstuck.blocked-worlds` | `[]` / `[]` | 世界允许与禁止列表，禁止列表优先 |

### 玩家管理（`player` 节）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `player.default-fly-speed` | `int` | `1` | `/speed fly reset` 使用的速度（1–10） |
| `player.default-walk-speed` | `int` | `1` | `/speed walk reset` 使用的速度（1–10） |
| `player.afk-timeout` | `int` | `300` | AFK 自动检测超时（秒，0=禁用自动检测） |
| `player.afk-kick-timeout` | `int` | `0` | AFK 后额外超时踢出（秒，0=不踢出） |
| `player.vanish-hide-quit-message` | `boolean` | `true` | 隐身时是否隐藏退出消息 |
| `player.vanish-hide-join-message` | `boolean` | `true` | 隐身时是否隐藏加入消息 |

### 传送系统（`teleport` 节）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `teleport.tpa-timeout` | `int` | `60` | TPA 请求自动过期时间（秒，最小 10） |
| `teleport.teleport-delay` | `int` | `3` | 传送预热延迟（秒，0=即时传送） |
| `teleport.cancel-on-move` | `boolean` | `true` | 预热期间移动是否取消传送 |
| `teleport.max-homes` | `int` | `3` | 每玩家可设置家数量上限（最小 1，可被权限覆盖） |
| `teleport.back-stack-size` | `int` | `5` | `/back` 返回位置栈最大深度（最小 1） |
| `teleport.safe-teleport` | `boolean` | `true` | 是否启用安全传送（自动寻找无碰撞位置） |

> 家数量上限支持权限覆盖：拥有 `axs.essentials.homes.<数字>` 权限的玩家可突破配置上限，模块从大到小遍历权限节点取最高值。

### 世界管理（`world` 节）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `world.allowed-worlds` | `list<string>` | `[]` | 允许 Essentials 命令和管理面板修改时间、天气的世界名称，空列表表示所有世界 |

### 安全管理（`moderation` 节）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `moderation.ban-message` | `string` | `&c你已被服务器封禁。\n&7原因: {reason}\n&7到期: {expiry}` | 封禁踢出消息（支持 `&` 颜色码与占位符） |
| `moderation.kick-message` | `string` | `&c你已被踢出服务器。\n&7原因: {reason}` | 踢出消息 |
| `moderation.mute-message` | `string` | `&c你已被禁言，无法发送消息。\n&7到期: {expiry}` | 禁言消息（发给被禁言玩家） |
| `moderation.max-warnings-before-ban` | `int` | `5` | 触发自动封禁的累计警告数（0=不自动封禁） |
| `moderation.warning-expire-days` | `int` | `30` | 警告记录过期天数（0=永不过期） |
| `moderation.allow-offline-bans` | `boolean` | `true` | 允许封禁服务端已知的离线玩家 |
| `moderation.history-page-size` | `int` | `10` | 每页处罚历史的条数（1–25） |

> 消息占位符：`{reason}` 封禁原因、`{expiry}` 到期时间（永久封禁显示"永久"）、`{player}` 玩家名、`{operator}` 操作者。

### 交互动作（`interaction` 节）

| `interaction.sit-on-slabs` | `boolean` | `false` | 右键点击半砖是否自动坐下 |

### 背包操作（`inv-actions` 节）

|--------|------|--------|------|
| `inv-actions.auto-replant.enabled` | `boolean` | `true` | 是否启用自动补种 |
| `inv-actions.auto-replant.permission` | `string` | `axs.essentials.replant` | 所需权限 |
| `inv-actions.auto-replant.crops` | `list<string>` | `[WHEAT, CARROTS, POTATOES, BEETROOTS, NETHER_WART]` | 支持的作物类型 |
| `inv-actions.auto-tool.enabled` | `boolean` | `true` | 是否启用自动工具切换 |
| `inv-actions.auto-tool.permission` | `string` | `axs.essentials.autotool` | 所需权限 |

## 传送配置示例

以下片段使用默认配置中的字段。修改原有 `teleport` 小节，保留未展示的其他设置：

```yaml
teleport:
  tpa-timeout: 60
  teleport-delay: 3
  cancel-on-move: true
  max-homes: 3
  back-stack-size: 5
  safe-teleport: true
```

请求有效期为 60 秒，传送预热 3 秒，预热时移动会取消传送。重载后用普通玩家测试请求、移动取消与家的数量限制。
