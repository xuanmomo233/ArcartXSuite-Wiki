## 开始前

安装并启用 `PlaceholderAPI`，用 `/axs status` 确认模块已加载。验收用普通玩家需要 `arcartxsuite.lottery.use`，该权限默认开启。

## 第一次使用

在测试服打开 `plugins/ArcartX-Suite/data/lottery/lottery/pools/`。如果改过 `pools-directory`，使用实际配置的目录。

1. 复制 `genshin_vanilla_event.yml` 为 `wiki_trial.yml`，将 `id` 改为 `wiki_trial`，并将 `gacha.shared-pity-group` 改为 `wiki_trial`。保留原文件的奖品和权重。
2. 将整个 `cost` 小节换成以下配置，单抽消耗 1 个原版黏土球。

```yaml
cost:
  single:
    - type: ITEM
      amount: 1
      display-name: "黏土球"
      icon:
        material: CLAY_BALL
      matcher:
        material-ids:
          - CLAY_BALL
```

3. 在控制台执行 `axs reload lottery`，等确认重载后执行 `axs lottery status`，确认列表有 `wiki_trial`。
4. 用背包有空位的普通玩家准备 1 个黏土球，进服执行 `/lottery open wiki_trial`，进行一次单抽。

## 检查是否配置成功

抽奖后应扣除 1 个黏土球并获得奖品。执行 `/lottery history wiki_trial` 应能看到这次记录。再次尝试单抽时，应提示材料不足，背包和记录保持原样。

找不到奖池时，核对 `pools-directory`、奖池的 `id` 和 `enabled`。奖池可打开却无法抽取时，按奖池类型检查消耗、箱子、钥匙和余额。 [奖池配置](/docs/lottery/configuration)

## 可以配置的功能

| 特性 | 说明 |
|---|---|
| GACHA 祈愿 | 原神风格祈愿，5 星/4 星硬保底、软保底递增、UP 概率、大保底/小保底、武器池命运点定轨机制，支持单抽与十连 |
| 多资源消耗 | 单次抽奖可同时消耗货币（CURRENCY）、物品（ITEM，含物品匹配器）、积分（POINT）三类资源 |
| 积分系统 | 每次抽奖按稀有度/星级累积积分，积分可在兑换商店兑换奖品 |
| 积分兑换商店 | 支持积分/物品/货币兑换奖品，支持限购次数（limit） |
| 跨池共享保底 | 同组 Gacha 池共享保底计数（通配符匹配池 ID 或奖池内显式声明 `shared-pity-group`） |
| 奖品投递 | 支持直接发放（DIRECT）、命令执行（COMMAND）、邮件发放（MAIL）三种投递方式 |
| 物品库支持 | 奖品与图标支持原版 / MythicMobs / NeigeItems / Overture / MMOItems |
| 抽奖历史记录 | 记录玩家抽卡/开箱历史，UI 可查看最近 100 条抽卡 / 20 条开箱记录 |
| 待发放奖励领取 | 投递失败的奖励自动入队，玩家上线或执行 `/lottery claim` 领取 |
