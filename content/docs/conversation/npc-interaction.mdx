## 前置条件

先确认 Chemdah、Adyeshach 和 Conversation 已启用。给一个现有 NPC 绑定 Chemdah 对话，再用普通玩家右键该 NPC，确认能打开 `ArcartXConversation` 主题。完整配置见[绑定 NPC](/docs/questgps/chemdah-walkthrough#第二步npc-对话接取任务)。

右键基线通过后，在 `plugins/ArcartX-Suite/data/conversation/config.yml` 检查 `interaction.enabled: true` 和 `ui.selector-ui-id`。使用自定义界面时，确认该 ID 能实际注册。选择器需要 ArcartX 客户端和注册成功的选择器 UI。

## 附近 NPC 扫描

模块默认每 10 tick 扫描玩家附近 6 格。扫描周期和范围分别由 `interaction.scan-period-ticks`、`interaction.scan-range` 控制。列表显示玩家附近可见、且在当前世界有适用对话绑定的 Adyeshach NPC。对话另设玩家条件时，用符合条件的账号测试打开。

- 玩家正在对话中选择器自动关闭
- NPC 离开范围后选择器保持一小段时间再关闭（`interaction.selector-sticky-ms`，默认 1500ms），防止短暂越界时频繁闪烁

## 选择器操作

选择器 HUD 展示附近可对话 NPC 列表（显示名与距离），当前选中项居中高亮：

| 操作 | 按键/方式 |
| --- | --- |
| 向上导航 | `AXS_NAVIGATE_PREV` 按键或滚轮 |
| 向下导航 | `AXS_NAVIGATE_NEXT` 按键或滚轮 |
| 确认打开对话 | `AXS_INTERACT` 按键或点击 |

### 验收同名 NPC 与世界范围

1. 用两个 Adyeshach NPC 测试。给它们相同的显示名、不同的实体 ID，只把其中一个 ID 绑定到 Chemdah 对话。重载对话后走进扫描范围，选择器应只列出有绑定的 NPC。
2. 使用带世界限制的对话绑定时，用同一个账号分别在允许世界和对照世界测试选择器。NPC 必须在该世界真实存在且对该玩家可见。超出扫描范围后等待选择器关闭，回到范围内再测试确认键。
3. 右键对话正常而选择器为空时，依次检查 `interaction.enabled`、界面注册、`scan-range`、NPC 的实际 ID 和世界限制。若绑定仍不显示，检查游戏服上的 Chemdah 是否支持该绑定写法，并在 Chemdah 重载后复测。

## 防抖与冷却

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `interaction.open-cooldown-ms` | `350` | 两次打开对话的最小间隔 |
| `interaction.suppress-reopen-ms` | `500` | 回复确认后抑制选择器重新打开的时长 |
| `interaction.selector-sticky-ms` | `1500` | NPC 离开范围后选择器保持显示的延迟 |

## NPC 外观自动配置

`npc-appearances` 配置节定义 NPC 名称到模型与动画的映射，模块启动 / 重载时自动应用：

```yaml
npc-appearances:
  - npc: "村长老王"
    model: npc_village_elder
    scale: 1.0
    state: idle
    animation: idle_loop
```

### 动画模式

| 模式 | 配置方式 | 说明 |
| --- | --- | --- |
| 持久默认状态 | 填 `state` + `animation`，不填 `animation-speed` | NPC 进入视野时保持持久动画 |
| 一次性播放 | 填 `animation` + `animation-speed`（`> 0`） | 播放一次动画，`state` 被忽略 |

### 应用时机

- 玩家进入 NPC 视野时立即应用模型与动画
- 玩家客户端 MOD 初始化完成后自动补发
- 模块启动时对尚未加载的 NPC 自动重试（最多 30 次），仍未找到的 NPC 输出警告日志

> NPC 名称匹配不区分大小写，NPC 的 displayName、customName、Adyeshach ID 均可匹配。

## 状态清理

玩家退出服务器或 Chemdah 对话结束时，该玩家的对话 UI、选择器 UI 与选择器状态自动清理；离线玩家的残留状态在扫描周期中自动移除。
