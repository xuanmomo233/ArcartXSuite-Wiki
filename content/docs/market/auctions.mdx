Market 的拍卖系统包含 **拍卖行**（竞价交易）和 **玩家商店**（固定价格交易）两个子系统，两者独立运作。

## 界面使用流程

### 拍卖大厅 → 单件拍品竞价厅

拍品卡上的“查看拍品实录”或“参与竞价”会进入独立竞价厅，也可以执行 `/market lot <拍品ID>` 直达。返回大厅会保留原来的分类、关键词与页码。

竞价厅分为三个区域：

- **拍品展示**：卖家、整组数量、起拍价、真实物品预览与物品说明；悬浮物品可查看原有提示。
- **竞价实录**：当前最高价、领先者、剩余时间、出价次数、独立竞价者人数、关注人数，以及最近 20 次有效出价。触发过延时的记录会显示实际延长秒数，结束后显示正式结算事件。
- **你的竞拍**：是否领先、是否被超价、是否得标、可用余额、当前押金、自己参与过的最高出价，以及只属于你的款项/物品交付进度。

页面人数来自真实出价及关注记录。竞价记录、最高价和被超价者的退款记录一起提交，失败出价不会进入竞价实录。截止倒计时仅作显示，正式落槌以服务端结算状态为准。

“最低有效价”“再加一档”“再加两档”只生成服务端报价，仍须确认；自定义金额同样先报价再确认，不会自动竞价。你的出价仍可在确认前被其他玩家超越，服务端将重新检查。

竞价厅约每两秒同步一次数据，收到本服或跨服的竞价变化也会请求更新；同步暂不可用时会提示，保留旧内容供查看，暂停新的出价入口。已打开的确认报价如遇到出价、截止时间或拍卖状态变化，会失效并要求重新报价。

大厅提供“即将结束”和“我的竞拍”：前者按实际截止时间排序，后者包含自己参与过的拍卖及已结束结果。命令分别为 `/market ending`、`/market bids`。“我的关注”可查看关注拍品的最终状态。

竞价厅使用 `ui.auction-room-ui-id`（默认 `AXS:market_auction_room`），其界面文件随模块导出为 `ui/market_auction_room.yml`。自定义 ID 时应与其他市场页面保持不同。

### 自定义出价与真实竞价状态

拍卖卡片区分起拍价、当前出价、领先者、剩余时间和结算状态。无人出价时显示“暂无出价”；到期后显示等待结算，成交、流拍、下架则各自显示最终状态，不再提供出价按钮。列表和已打开的报价会定期读取最新状态。

在竞价厅选择「最低有效出价」，或通过「自定义金额并确认」输入金额，再点「更新报价」或按回车。报价显示最低金额、领先者、冻结金额、追加扣款和截止时间。金额变化后须重新报价并确认。

首次出价可等于起拍价；后续最低出价为 `当前最高价 + max(当前最高价 × 比例加价, 固定加价)`，向上取到货币支持的精度。服务端报价在 15 秒内可确认一次。切换竞价页、修改金额或拍品状态变化后需要重新报价。旧报价会在扣款前被拒绝。

未领先时按完整出价扣款，领先时加价只扣差额。出价被超过后，原押金进入退款流程。退款和物品进度见交易流水。

### 关注商品和提醒

点击星标关注或取消关注，每位玩家最多关注 100 件商品。“我的关注”分类可搜索和查看关注商品，也保留已结束拍卖的状态。

默认提醒被超价者、成交卖家和得标买家，并告知关注者商品的成交、流拍或取消结果。通知先保存，离线玩家上线后接收。`auction.notifications.watch-bids` 可额外开启每次出价提醒，默认关闭以减少打扰。被超价提醒的位置使用 `outbid-notify: chat/actionbar/title`。

### 可选临近结束延时

```yaml
auction:
  allow-cancel-with-bids: false
  end-protection:
    enabled: true
    window-seconds: 120
    extend-seconds: 120
    max-extension-seconds: 1800
  notifications:
    outbid: true
    settlement: true
    watch-bids: false
```

延时默认关闭。以上示例表示：剩余不超过 120 秒时有有效出价，将截止时间调整为“不早于当前截止时间、出价处理时间后 120 秒”，但最多比原截止时间延后 1800 秒。达到累计上限后不会无限延长。无效、失败或未确认的报价不触发延时。

截止时间与出价一起提交；结算重新读取最新挂单，避免延时后仍按旧时间结算。多服市场必须共享数据库，跨服拍卖消息只通知界面缓存更新，不重复执行竞价。

统一上架页面 `/market sellui` 可以选择交易模式、背包物品、价格、货币和时长。可选模式与时长受对应功能配置限制；从玩家商店进入上架页时默认选中玩家商店模式。

拍卖出价会先显示本次金额并提醒出价时扣款；确认后提交。拍卖与玩家商店下架均需确认。玩家商店价格是整组商品的总价，购买确认会显示数量与金额，小数价格会保留显示。

竞价、购买、下架后保留当前分类、搜索及页码；玩家商店也保留卖家筛选。左侧按钮可在“我的商品”与全部卖家之间切换，自己的商品显示下架入口。列表刷新按钮会请求最新数据。

玩家商店左侧的卖家列表可独立翻页；选中卖家后搜索会在该卖家的商品中查找。切换为全部卖家后，相同关键词会搜索整个玩家市场。

交易失败后操作按钮会恢复，已输入的上架表单不因失败而清空；成交与退还情况可在 `/market history` 查看。

## 拍卖行

拍卖行是玩家间的纯竞价交易系统。卖家上架物品设定起拍价，买家竞价，到期后价高者得。

### 拍卖配置结构

拍卖行配置位于 `config.yml` 的 `auction` 节，详见 [配置 - 拍卖行配置](/docs/market/configuration#拍卖行配置-auction)。

### 上架流程

1. 玩家通过 `/market sell <起拍价> [时长] [货币]` 或上架界面提交。服务端验证价格、时长、留言、货币、黑名单与物品来源槽位。
2. 后台核对在售和正在暂存的挂单数量，保存物品快照和上架费意图。涉及上架费时，扣费结果确认后才进入物品扣除。
3. 服务端复核会话与来源槽位，只扣除请求的数量，并把扣除凭证随背包一起自然保存。
4. 原子服读到匹配的扣除凭证后发布挂单，从发布时起计算完整拍卖时长，并刷新缓存和跨服列表。

<Callout type="info" title="物品安全">
暂存阶段会提示等待保存。若扣费后槽位发生变化，上架会取消，已确认的费用进入退款队列。上架费结果不明时，可通过 `/axs market pshop-review` 核对后退款或释放暂存。
</Callout>

### 竞价流程

1. 玩家在 UI 输入金额并获取报价，再确认出价
2. 校验：
   - 物品处于 ACTIVE 状态且未过期
   - 出价者不能是卖家本人
   - 出价 ≥ 最低出价
3. 先保存扣款意图，再按当前是否领先扣除全额或差额。
4. 等待出价结果。多人同时出价时，未生效的出价会按扣款结果安排退款。被超价的玩家也可在交易流水查看退款。扣款结果不明时，请保留流水编号供管理员核对。
5. 持久保存提醒，记录竞价历史并刷新列表

### 最低出价计算

```
最低出价 = 当前最高价 + max(当前最高价 × min-bid-increment-ratio, min-bid-increment-absolute)
```

| 场景 | 当前最高价 | ratio | absolute | 最低出价 |
|---|---|---|---|---|
| 首次出价 | 起拍价 100 | - | - | 100（等于起拍价） |
| 第二次出价 | 100 | 0.05 | 10 | 110（max(105, 110)） |
| 高价出价 | 10000 | 0.05 | 10 | 10500（max(10500, 10010)） |

#### 有人竞价（SOLD）

1. 计算税费：`税 = 成交价 × 有效税率`。有效税率取基础税率与匹配权限最终税率中的最低值；离线玩家通过 LuckPerms 查询权限。
2. 同时保存成交状态、`BID_WIN` 交易历史、卖家收入和买家物品的交付任务。
3. 交付队列向卖家支付 `成交价 - 税`，向买家发放物品。离线时保留任务，到账情况见交易流水。

成交邮件在 [EventPacket](/docs/eventpacket/triggers) 配置 `auction-purchased` 规则，适用于到期竞价成交。处理失败或服务器重启后可继续发放，到账以物品和款项各自的记录为准。

#### 无人竞价（EXPIRED）

1. 同时保存流拍状态、`EXPIRED` 交易历史和物品退还任务。
2. 向卖家退还物品并发送流拍提醒，离线时保留交付任务。

### 取消上架

卖家可取消自己尚未到期且无人有效出价的物品。设为 `allow-cancel-with-bids: true` 后，卖家也可取消尚未到期的有出价拍品，领先者的押金会进入退款队列。

撤单成功后，在交易流水查看押金退款和拍品返还进度。跨服列表暂未刷新时，请以撤单结果和交易流水为准。

管理员可通过 `/axs market remove <ID>` 强制下架仍处于活动状态的拍品，交易历史记录为 `ADMIN_CANCELLED`。

### 手续费配置

| 配置项 | 说明 |
|---|---|
| `listing-fee` | 上架手续费（固定金额，上架时立即扣除，无论是否成交） |
| `listing-fee-currency` | 手续费货币类型 |
| `transaction-tax-rate` | 成交税率（从卖家最终收入中扣除） |
| `transaction-tax-currency` | 税费货币类型 |
| `tax-discount` | 权限节点 → 最终税率，取匹配的最低税率 |

#### 税率计算示例

```
基础税率 = 5%
VIP 最终税率 = 2%（权限 axsmarket.vip）
MVP 最终税率 = 1%（权限 axsmarket.mvp）

VIP 玩家有效税率 = 2%
MVP 玩家有效税率 = 1%
同时拥有 VIP + MVP = 1%
```

### 分类系统

拍卖行通过 NBT/PDC 路径自动分类物品。分类用于 UI 筛选功能。

```yaml
auction:
  categories:
    weapon:
      display-name: "&c武器"
      priority: 10
      nbt:
        path: "pdc:arcartx:item_category"
        values: ["weapon"]
    other:
      display-name: "&7其他"
      priority: 9999
      default: true
```

分类匹配逻辑：
1. 按优先级（`priority` 升序）遍历所有分类
2. 读取物品 PDC 中 `path` 指定的键值
3. 若值匹配 `values` 列表中的任一项，归属此分类
4. 未匹配任何分类时归入 `default: true` 的分类

## 玩家商店

玩家商店允许玩家以固定价格上架物品，其他玩家可直接购买（无竞价机制）。与拍卖行独立运作。

### 与拍卖行的区别

| 对比项 | 拍卖行 | 玩家商店 |
|---|---|---|
| 交易方式 | 竞价 | 固定价格直接购买 |
| 价格机制 | 起拍价 + 竞价加价 | 固定价格 |
| 最长上架时长 | 7 天 | 30 天 |
| 默认上架时长 | 24 小时 | 7 天 |
| 每人上架上限 | 10 件 | 20 件 |

### 购买流程

1. 买家在界面确认购买，服务端复核商品和当前店铺。
2. 后台先保存商品预留、扣款意图和交付快照。只有抢占成功的请求会扣款。
3. 购买成功后，买家在背包查看物品，卖家收到扣除税费后的款项。暂未到账时，在交易流水查看交付进度。
4. 成交提交后刷新缓存和跨服列表，卖家可通过交易通知查看结果。

扣款结果不明时，商品保持预留，交易进入人工核对。管理员核对经济流水后，可通过 `/axs market pshop-review <订单ID> <fulfill-paid|refund-paid|cancel-unpaid> <核对依据>` 完成已付款订单、安排退款，或释放确认未扣款的商品。

### 下架流程

卖家可下架自己的商品，管理员也可通过市场命令下架。下架或到期时，商品状态、交易历史和物品返还记录一起提交。可在交易流水查看物品的交付进度。

### 卖家浏览

用 `/market pshop` 打开店铺目录，按店名或店主查找。店铺资料、在售商品与收藏见[玩家独立店铺](/docs/market/shops#玩家独立店铺)。

## 跨服竞价

拍卖行和玩家商店均支持跨服同步。启用 `cross-server.enabled: true` 后：

| 同步内容 | 说明 |
|---|---|
| 上架创建 / 取消 | 各服失效本地缓存 |
| 竞价 | 各服同步最新竞价 |
| 玩家商店上架 / 购买 / 下架 | 各服失效缓存 |
| 限购更新 | 各服同步限购记录 |
| 动态商品 | 各服同步动态商品状态 |

### 通过命令上架

```
/market sell 1000 86400 money
```

将手持物品以起拍价 1000、时长 86400 秒（24 小时）、货币 money 上架到拍卖行。

### 通过 UI 上架

1. 执行 `/market` 打开拍卖行 UI
2. 点击上架按钮打开上架 UI
3. 选择背包中的物品
4. 输入起拍价、时长、货币、留言
5. 确认上架

### 竞价

在拍卖行 UI 中点击物品，输入出价金额。系统会自动计算最低出价并提示。

### 搜索

```
/market search 钻石剑
```

打开拍卖行 UI 并搜索"钻石剑"（同时匹配物品名、拼音 `zuan shi jian`、首字母 `z s j`）。

### 查看我的上架

```
/market my
```

打开拍卖行 UI 并筛选显示自己的上架物品。

### 取消上架

```
/market cancel 42
```

取消上架 ID 为 42 的物品（退还竞价押金 + 返还物品）。

### 玩家商店上架

通过 `/market sellui` 打开上架界面，选择玩家商店并填写整组售价。确认后商品先暂存，服务端读到背包扣除的存档凭证后按固定价格发布。发布后从 `/market pshop mine` 查看在售商品。

同一玩家同时只能有一笔等待存档或核对的上架。上架费结果不明时，可通过 `/axs market pshop-review <订单ID> <refund-paid|cancel-unpaid> <核对依据>` 处理。服务器重启后，原子服会重新读取存档凭证。
