title: "鱼竿配置"

---

鱼竿定义文件位于 `plugins/ArcartX-Suite/data/fishing/rods/` 目录下，每个 `.yml` 文件定义一种鱼竿。

## 鱼竿识别机制

鱼竿定义用来识别手持的原版钓竿，并为它设置加成。系统先检查各定义的 `match` 规则，再读取物品的 PDC 字符串 `arcartx-suite:axs_fishing_rod_id`。字符串的值应等于鱼竿定义的 `id`。

发放轻盈钓竿时，由物品插件或服务器的发放流程写入这个字符串，值为 `light_rod`。物品的显示名可按服内风格设置。

使用外部物品配置工具时，将该键设为字符串类型。如果通过 Bukkit 插件发放，可在交付前为钓竿写入这个键。

```java
var rod = new ItemStack(Material.FISHING_ROD);
var meta = rod.getItemMeta();
meta.getPersistentDataContainer().set(
    NamespacedKey.fromString("arcartx-suite:axs_fishing_rod_id"),
    PersistentDataType.STRING,
    "light_rod"
);
rod.setItemMeta(meta);
```

当玩家手持物品不匹配任何鱼竿定义时，使用默认鱼竿（`RodDefinition.DEFAULT`，无任何加成）。

## 鱼竿定义字段

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `id` | string | 文件名 | 鱼竿唯一标识符 |
| `match` | map | - | 物品匹配规则，写法与示例见[物品匹配与消耗](/docs/guide/item-matching) |
| `treasure-chance-bonus` | double | `0.0` | 宝藏概率加成（加到基础概率上） |
| `green-bar-height-bonus` | int | `0` | 绿条高度加成（像素） |
| `catch-duration-bonus` | int | `0` | 小游戏持续时间加成（ticks） |
| `line-strength` | double | `1.0` | 张力承受倍率，范围 0.25–4。数值越高，鱼挣扎时张力涨得越慢 |
| `turn-response` | double | `1.0` | 绿条反向时的响应倍率，范围 0.25–4 |
| `exp-multiplier` | double | `1.0` | 捕获经验倍率 |
| `min-player-level` | int | `0` | 最低赛季等级（0 = 不限） |
| `max-player-level` | int | `0` | 最高赛季等级（0 = 不限） |

### 效果说明

| 效果 | 计算方式 |
| --- | --- |
| 宝藏概率加成 | `最终概率 = fishing.treasure-chance + 饵料treasure-chance-boost + 鱼竿treasure-chance-bonus` |
| 绿条高度加成 | `绿条高度 = 基础高度 + 等级×height-per-level + 鱼竿green-bar-height-bonus + 天赋bar_height` |
| 持续时间加成 | `实际超时 = 基础超时 × 难度系数 × (1 + 天赋catch_duration加成) + 鱼竿catch-duration-bonus` |
| 经验倍率 | `最终经验 = 鱼baseXp × 尺寸因子 × 鱼竿exp-multiplier × (1 + 天赋xp_multiplier加成) × (完美 ? 1.5 : 1)` |

### match 物品匹配规则

`match` 中不同字段需要同时满足；单个列表内通常任选一项，`nbt-values` 内多个键值则全部满足。不要同时填入两种物品库 ID 并期待任选其一。

| 字段 | 说明 |
| --- | --- |
| `neige-item-ids` | NeigeItems 物品 ID 列表 |
| `mythic-item-ids` | MythicMobs 物品 ID 列表 |
| `overture-item-ids` | Overture 物品 ID 列表 |
| `material-ids` | 原版材质名列表（如 `[fishing_rod]`） |
| `name-contains` | 显示名需包含的子串列表 |
| `lore-contains` | Lore 需包含的子串列表 |
| `nbt-keys` | 列表，检查标签存在，例如 `nbt-keys: [rod_id]`；真实物品需要已带有该键 |
| `nbt-values` | 映射，检查具体值，多个键值全部满足；完整写法见下方例子 |
| `name-regex` / `lore-regex` | 字符串列表；完整名称可写 `name-regex: ['^青玉钓竿$']` |

### 按标签识别鱼竿

如果鱼竿已有值为 `jade_rod` 的 `rod_id` 标签，在 `plugins/ArcartX-Suite/data/fishing/rods/jade_rod.yml` 创建定义。

```yaml
id: jade_rod
match:
  material-ids:
    - fishing_rod
  nbt-values:
    "rod_id": "jade_rod"
green-bar-height-bonus: 8
exp-multiplier: 1.1
min-player-level: 0
max-player-level: 0
```

执行 `axs reload fishing` 后，分别用带正确标签和无标签的原版鱼竿试钓。前者应获得绿色目标条与经验加成。标签由实际物品配置提供，获取方法见[物品匹配](/docs/guide/item-matching#nbtpdc-标签从哪里获取)。

### 鱼竿耐久度

鱼竿耐久度消耗受饵料 `max-durability-bonus` 影响。当玩家使用鱼竿钓鱼时，`PlayerItemDamageEvent` 被拦截：

- 计算耐久度加成值
- `新损耗 = max(0, 原损耗 - 加成值)`
- 新损耗为 0 时取消事件，否则修改损耗值

### 基础木制钓竿

```yaml
id: "wooden_rod"
match:
  neige-item-ids: [wooden_fishing_rod]
  # 或用原版材质匹配（所有原版鱼竿都视为木制钓竿）
  # material-ids: [fishing_rod]
treasure-chance-bonus: 0.05
green-bar-height-bonus: 8
catch-duration-bonus: 60
exp-multiplier: 1.1
min-player-level: 0
max-player-level: 0
```

### 进阶鱼竿（等级限制）

```yaml
id: "iron_rod"
match:
  neige-item-ids: [iron_fishing_rod]
treasure-chance-bonus: 0.10
green-bar-height-bonus: 16
catch-duration-bonus: 120
exp-multiplier: 1.3
min-player-level: 20
max-player-level: 0
```

### 传说鱼竿（高等级专属）

```yaml
id: "legendary_rod"
match:
  mythic-item-ids: [legendary_fishing_rod]
treasure-chance-bonus: 0.20
green-bar-height-bonus: 32
catch-duration-bonus: 200
exp-multiplier: 2.0
min-player-level: 50
max-player-level: 0
```

## 默认鱼竿

当玩家手持物品不匹配任何鱼竿定义时，使用默认鱼竿 `RodDefinition.DEFAULT`：

| 属性 | 值 |
| --- | --- |
| id | `default` |
| treasure-chance-bonus | 0.0 |
| green-bar-height-bonus | 0 |
| catch-duration-bonus | 0 |
| exp-multiplier | 1.0 |
| min-player-level | 0 |
| max-player-level | 0 |

> 默认鱼竿不施加任何加成，确保新手玩家也能正常钓鱼。
