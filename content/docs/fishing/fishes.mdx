---
title: "鱼类配置"
description: "定义鱼类的稀有度、尺寸、售价、出现条件和小游戏行为。"
---

鱼类定义文件位于 `plugins/ArcartX-Suite/data/fishing/fishes/` 目录下，每个 `.yml` 文件定义一种鱼。模块首次启动时会自动导出默认鱼类文件，用户已修改的文件不会被覆盖。

## 先让鱼出现，再调难度

鱼类定义负责“这条鱼是什么”，水域配置负责“在哪里能抽到这条鱼”。新建文件后，还要到目标水域的鱼群分布中引用其 `id`。文件名和显示名不能代替这条引用。

1. 从下方鲤鱼示例复制一份，先改 `id`、`display-name` 和原版物品。
2. 在实际测试水域引用该 ID。先使用常见鱼和较低难度。
3. 暂时放宽季节、天气、时间、等级、权限和水深，先确认能钓到。
4. 每次只增加一项限制，重载后到同一水域验证。
5. 最后调整小游戏行为、售价、经验和额外奖励。

### 不同字段先影响哪里

| 配置 | 直接影响 | 调整场景 |
| --- | --- | --- |
| `id` | 水域和其他配置引用这条鱼 | 新建鱼类时保持唯一 |
| `display-name`、`description` | 名称与介绍 | 改中文展示，通常不需要改 ID |
| `seasons`、`weathers`、`time-ranges` | 是否进入当前候选范围 | 做季节鱼、雨天鱼或夜钓鱼 |
| 等级、权限、生物群系和水深 | 哪些玩家和地点可捕获 | 开放进阶水域时逐项启用 |
| `difficulty`、`behaviors` | 小游戏难度与鱼的运动 | 已确认出现后再调操作手感 |
| `item`、`icon` | 实际鱼物品与界面图标 | 先用原版物品确认生成，再接物品库 |
| 售价、经验、额外奖励 | 捕获后的收益 | 防止“获得鱼物品”和“额外发物品”重复设计 |

修改后重载 Fishing，到测试水域确认名称、图标、出现条件、小游戏和收益。水域分布的结构见[水域配置](/docs/fishing/pools)，下方示例的鱼 ID 需与水域引用完全一致。

### 基础属性

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `id` | string | 文件名 | 鱼类唯一标识符 |
| `display-name` | string | id | 显示名称（支持颜色代码 `&`） |
| `rarity` | string | `COMMON` | 稀有度（`COMMON`/`UNCOMMON`/`RARE`/`LEGENDARY`） |
| `min-size` | int | `1` | 最小尺寸（厘米） |
| `max-size` | int | `10` | 最大尺寸（厘米） |
| `base-price` | int | `10` | 基础售价 |
| `base-xp` | int | `5` | 基础经验值 |
| `difficulty` | int | `30` | 钓鱼难度（0-100） |
| `record-weight` | double | `1.0` | 图鉴排序权重（越大越靠前） |
| `description` | string | - | 鱼类描述（图鉴展示） |

### 出现条件

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `seasons` | list | 全部 | 可捕季节（`spring`/`summer`/`fall`/`winter`） |
| `weathers` | list | `["clear", "rain"]` | 可捕天气（`clear`/`rain`） |
| `time-ranges` | list | `06:00-20:00` | 可捕时段（`start`/`end`，支持跨午夜） |
| `min-player-level` | int | `0` | 最低钓鱼等级（0 = 不限） |
| `max-player-level` | int | `0` | 最高钓鱼等级（0 = 不限） |
| `require-permission` | string | - | 钓到此鱼所需权限 |
| `biomes` | list | 不限 | 生物群系限制（如 `[river, ocean]`） |
| `depth-range.min-depth` | int | `0` | 最小水深（方块深度，从水面往下） |
| `depth-range.max-depth` | int | `256` | 最大水深 |

### 物品与图标

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `item` | map | `minecraft:cod` | 捕获后掉落的物品（[IconDefinition](/docs/guide/icons) 格式） |
| `icon` | map | 回退到 item | 图鉴/小游戏中的鱼图标 |

`item` 和 `icon` 支持 `source: minecraft/mythic/neige/overture/mmoitems`，详见 [物品来源](/docs/guide/item-sources)。

### 小游戏行为

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `behavior-mode` | string | `random`（默认）按权重抽取动作，`sequence` 按列表顺序执行，完成后从头循环 |
| `behaviors` | list | 每项填写 `type`。`random` 可用 `weight` 设置抽取权重，默认为 `1` |
| `behaviors[].duration-ticks` | int | 动作持续的小游戏更新步数。`sequence` 每项必填正整数。`random` 填正整数时到期重新抽取，省略或填 `0` 时持续到阶段切换或本局结束 |
| `behavior-stages` | map | 到达 `threshold` 后进入该阶段。每个阶段可独立设置 `behavior-mode` 和 `behaviors` |

下面的鱼在前半段随机选动作，进度达到 `0.60` 后，按下沉、上浮、摆动的顺序循环。进度掉回阈值以下时会切回前一阶段，再进入顺序阶段会从第一项开始。默认每次小游戏更新约为 50 毫秒。

```yaml
behavior-mode: random
behaviors:
  - type: smooth
    weight: 2
    duration-ticks: 24
  - type: dart
    weight: 1
    duration-ticks: 16
behavior-stages:
  late:
    threshold: 0.60
    behavior-mode: sequence
    behaviors:
      - type: sinker
        duration-ticks: 18
      - type: floater
        duration-ticks: 22
      - type: zigzag
        duration-ticks: 12
```

`sequence` 固定动作顺序和基础持续时间。各动作本身的抖动、突进以及独立的逃离机制仍按鱼种配置运行。

### 读招、张力和途中宝藏

动作可加 `tell-ticks` 和 `recovery-ticks`，单位都是小游戏更新步数。填写任一项时，`duration-ticks` 必须为正整数，表示实际移动的时长。预警箭头显示本次锁定的方向。配置了预警和回稳的动作执行完后，才检查进度并安排下一招。

```yaml
line-tension:
  enabled: true
active-treasure:
  enabled: true
behavior-mode: sequence
behaviors:
  - { type: sinker, tell-ticks: 12, duration-ticks: 17, recovery-ticks: 32 }
  - { type: floater, tell-ticks: 12, duration-ticks: 17, recovery-ticks: 32 }
```

- `line-tension.enabled` 开启后，鱼挣扎时张力上升。按 `R` 松线可降张力。松线期间倒计时继续，命中暂时停止涨进度。张力满后超过宽限时间会断线。
- `active-treasure.enabled` 开启后，本局抽中的宝藏会在合适的回稳窗口出现。把绿条移过去连续覆盖 8 步可捞取，收竿成功后才发奖。此模式需要配置足够长的回稳窗口。
- 鲫鱼可练固定读招，鲶鱼可练随机动作和捞宝，传说鲤鱼会用到松线。已有安装试用时，先更新 `ui/fishing_minigame.yml`，再将需要的样例设置合并到模块的鱼种、竿、饵和水域文件。

### 体型差异

传说鲤鱼在咬钩时抽取 80～250 cm 的体型。本局的冲刺速度、冲刺时长和拉力按体型在 `small` 与 `large` 之间线性变化。固定尺寸的鱼取两端的中点，省略倍率时按 `1.0`，可填写 `0.25`～`4.0`。

```yaml
size-difficulty:
  small: { rush-speed: 1.15, rush-duration: 0.90, pull: 0.85 }
  large: { rush-speed: 0.85, rush-duration: 1.20, pull: 1.25 }
```

小鱼冲得更快，大鱼的冲刺阶段更长、拉力更高。预警与回稳时长由动作配置决定。拉力倍率在开启张力的对局生效，擦线额外张力由[落点障碍](/docs/fishing/pools#落点障碍)配置。

### 鱼的体力

设置 `stamina` 后，鱼从 100% 体力开始，每个读招冲刺步扣除 `rush-drain-per-tick` 个百分点。体力耗尽后等本次冲刺结束，再进入力竭窗口。力竭时长超过原本的回稳期则延长回稳，窗口结束后鱼回满体力。

```yaml
stamina:
  rush-drain-per-tick: 3.0
  exhausted-ticks: 20
  progress-gain-multiplier: 1.40
```

力竭时，绿条命中且鱼线未放松，收线进度乘以 `progress-gain-multiplier`（`1.0`～`3.0`）。松线期间力竭计时照常前进。配合带有 `tell-ticks` 或 `recovery-ticks` 的动作配置使用。

### 个体性格与提竿

传说鲤鱼在咬钩开局时抽取一个性格，界面会显示本局结果。权重 `7 / 2 / 1` 分别对应普通、警觉和顽强。

```yaml
personalities:
  normal-weight: 7
  variants:
    alert: { display-name: "警觉", weight: 2, first-miss-rush: true }
    resilient: { display-name: "顽强", weight: 1, stamina-drain-multiplier: 0.65 }
hook-set:
  tap-ticks: 12
  window-ticks: 8
  late-ticks: 12
  good-recovery-bonus: 8
  miss-recovery-penalty: 4
```

- `first-miss-rush` 在鱼曾被绿条命中、随后首次脱靶时生效。等当前招式结束后补一次有方向预警的冲刺，每局最多一次。
- `stamina-drain-multiplier` 调整读招冲刺的体力消耗。示例的顽强鲤鱼每步消耗普通个体的 65%。
- 配置 `hook-set` 后，真实咬钩会先出现提竿提示。浮漂轻点时等待，沉漂亮绿时按 `F`。第一下提竿决定结果，开场提竿期间对抗倒计时暂停。
- 准点增加第一招的回稳步数。早提、晚提或错过窗口均继续对抗，并缩短第一招回稳。回稳修正适用于有预警或回稳的动作。

**行为类型**（`FishBehaviorType`）：

| 类型 | 说明 |
| --- | --- |
| `SMOOTH` | 平滑型：多频率正弦叠加 + 随机噪声 + 偶发突进 + 停留抖动 |
| `DART` | 突进型：不规则间隔突进 + 游荡 + 偶发停留 |
| `SINKER` | 下沉型：整体下沉 + 不规则波动 + 偶发上突 |
| `FLOATER` | 上浮型：整体上浮 + 不规则波动 + 偶发下突 |
| `MIXED` | 混合型：在 smooth/dart/sinker/floater 之间随机切换 |
| `ZIGZAG` | 之字型：沿轨道往复摆动，幅度和频率随难度增加 |
| `IDLE` | 停滞型：长时间几乎不动，偶尔突然突进 |

### 小游戏机制覆盖（可选）

每条鱼可独立覆盖全局配置的进度参数和逃离参数。未配置的字段使用全局默认值。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `progress-gain.base-rate` | double | 鱼在绿条内时进度上升速率（覆盖全局 base-rate，formula 沿用全局） |
| `progress-drain.base-rate` | double | 鱼在绿条外时进度下降速率（覆盖全局 base-rate，formula 沿用全局） |
| `flee-params.*` | map | 覆盖全局逃离参数（见下表） |

`flee-params` 可覆盖的字段（全部可选，null 表示用全局默认值）：

| 字段 | 说明 |
| --- | --- |
| `base-chance` | 逃离基础概率 |
| `chance-per-difficulty` | 每点难度增加的逃离概率 |
| `base-speed` | 逃离基础速度 |
| `speed-per-difficulty` | 每点难度增加的逃离速度 |
| `min-duration` / `max-duration` | 逃离持续 ticks 范围 |
| `check-min-interval` / `check-max-interval` | 逃离检查间隔 ticks 范围 |
| `cooldown-min` / `cooldown-max` | 逃离冷却 ticks 范围 |

### 奖励配置

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `currency-reward` | map | 单个货币奖励（`currency-id` + `amount`） |
| `currency-rewards` | list | 多货币奖励列表（与 `currency-reward` 叠加生效） |
| `drops` | map | 额外物品掉落（支持条件掉落） |
| `command-rewards` | list | 命令奖励（以控制台身份执行） |

**条件掉落**（`drops` 中的 `condition` 字段）：

| 条件 | 说明 |
| --- | --- |
| `""` | 无条件 |
| `perfect` | 完美捕获时掉落 |
| `size:N` | 尺寸 ≥ N cm 时掉落 |
| `first_catch` | 首次捕获此鱼时掉落 |

多条件用逗号分隔（全部满足才掉落），如 `"perfect,size:200"`。

**命令奖励**支持占位符：`{player}`（玩家名）、`{fish}`（鱼 ID）、`{size}`（尺寸）。

## 稀有度系统

| 稀有度 | 权重乘数 | 说明 |
| --- | --- | --- |
| `COMMON` | 1.0 | 常见，出现概率最高 |
| `UNCOMMON` | 0.6 | 不常见 |
| `RARE` | 0.4 | 稀有 |
| `LEGENDARY` | 0.1 | 传说级，出现概率极低 |

稀有度权重乘数参与鱼池的加权随机选择。最终权重计算：

```
权重 = rarity.weightMultiplier()
     × 饵料吸引倍率（bait.fishAttractModifiers[fishId]）
     × 鱼饵偏好倍率（fish.baitPreferences[baitId].multiplier）
     × 水域饵料倍率（water.baitMultipliers[baitId]）
```

## 尺寸与价格计算

捕获尺寸在 `[min-size, max-size]` 范围内随机。尺寸影响经验和售价：

- **尺寸因子** = `(caughtSize - minSize) / (maxSize - minSize)`，clamp 到 [0.5, 1.5]
- **经验** = `baseXp × 尺寸因子`，完美捕获额外 ×1.5
- **售价** = `basePrice × 尺寸因子`

### 疲惫值特殊鱼

疲惫值 > 90 时有概率出现的特殊鱼类，配置方式与普通鱼类一致。在 `fatigue.yml` 的 `special-fishes` 列表中引用其 ID 即可。

```yaml
id: fatigue_ghost_fish
display-name: "幽灵鱼"
rarity: LEGENDARY
min-size: 1
max-size: 15
base-price: 500
base-xp: 100
seasons: [spring, summer, fall, winter]
weathers: [clear, rain]
time-ranges:
  default:
    start: "00:00"
    end: "24:00"
item:
  source: minecraft
  id: cod
  amount: 1
difficulty: 75
min-player-level: 10
behaviors:
  smooth:
    type: SMOOTH
    weight: 0.5
  erratic:
    type: DART
    weight: 0.5
currency-reward:
  currency-id: "money"
  amount: 100
description: "极度疲惫时出现的幽灵之鱼，据说只有在精疲力竭时才能看到它的身影"
record-weight: 2.0
```
