## 第一次使用

1. 确认游戏服已启用 `tab` 模块，玩家使用 ArcartX 客户端。
2. 打开 `plugins/ArcartX-Suite/data/tab/config.yml`，在 `settings.layout` 选 `simple` 或 `avatar`。
3. 执行 `/axs reload tab`，进服按住 Tab 查看名单。

## 检查是否配置成功

用两个在线账号检查玩家名。选择 `avatar` 时也应看到头像和延迟。如果没有自定义界面，先用 `/axs status` 确认模块已加载，再核对布局名称。
