---
title: "在线列表配置"
description: "选择精简名单或头像名单，设置是否向 Velocity 汇报名单状态。"
---

主配置文件位于 `plugins/ArcartX-Suite/data/tab/config.yml`。保存后执行 `/axs reload tab`。

```yaml
settings:
  layout: simple
  proxy-roster: false
```

| 字段 | 用途 |
| --- | --- |
| `settings.layout` | `simple` 显示玩家名，`avatar` 额外显示头像和延迟。 |
| `settings.proxy-roster` | 启用时向 Suite Velocity 上报当前连接的准入和隐身状态。单服使用默认值 `false`。 |

## 切换与验证布局

一次选择一个布局。保存 `settings.layout` 后执行 `axs reload tab`，用 ArcartX 客户端进服按住 Tab。选择 `avatar` 时，应在名单中看到头像和延迟。

在 `plugins/ArcartX-Suite/ui/tab/` 编辑当前布局对应的 `tab-simple.yml` 或 `tab-avatar.yml`，保存后重载 Tab。界面从 ArcartX 客户端读取原版 Tab 名单。付费客户水印版的多子服名单同步见[跨服名单](/docs/tab/cross-server)。
