title: "Velocity 跨服名单"
description: "在 Velocity 代理中汇总参与子服的玩家，验证准入和隐身状态。"
---

## 启用跨服名单

1. 在各参与子服的 `plugins/ArcartX-Suite/data/tab/config.yml` 中设置 `settings.proxy-roster: true`，执行 `/axs reload tab`。
2. 在 Suite Velocity 插件的 `proxy-config.yml` 中加入以下设置，保存后重启代理。

```yaml
tab-list:
  enabled: true
  max-remote-entries: 80
```

`max-remote-entries` 是每个名单额外显示的远端玩家上限，可填 1～80，默认 80。代理只有在确认远端玩家已通过准入且可见时才会展示该玩家。跨服传递隐身状态需要各参与子服使用 Paper 的 Velocity modern forwarding，并启用 Suite Essentials 和 Tab。

## 检查显示与隐身

用两个账号分别进入不同子服，按 Tab 检查是否能看到对方。让其中一个账号隐身并切服，另一个账号重新查看名单，确认该账号仍处于隐藏状态。
