## 启用跨服名单

通过 Suite Velocity 汇总多个子服的名单适用于付费客户水印版。 [版本区别](/docs/guide#版本区别)

1. 从客户分发渠道取得 Suite Velocity，在连接这些子服的代理上安装。子服启用 Tab，在各自的 `plugins/ArcartX-Suite/data/tab/config.yml` 中设置 `settings.proxy-roster: true`，再执行 `axs reload tab`。
2. 在 Velocity 的 Suite 插件目录中编辑已生成的 `proxy-config.yml`，合并以下设置后重启代理。

```yaml
tab-list:
  enabled: true
  max-remote-entries: 80
```

`max-remote-entries` 限制远端名单人数，可设为 1～80，默认 80。名单只显示已通过进服验证且可见的远端玩家。跨服隐身要求各子服启用 Paper 的 Velocity modern forwarding，以及 Suite Essentials 和 Tab。

在启用跨服名单的子服，`/vanish` 经代理确认后生效。请等隐身状态更新再切服，在切服完成后再开启隐身。

## 检查显示与隐身

用两个已准入的测试账号分别进入子服 A 和 B，按 Tab 确认双方都能看到对方。再用有权限的账号开启隐身，先确认另一人的名单中已消失，然后切服并重新查看名单。关闭隐身后，确认可见玩家重新出现。
