## 启用跨服名单

1. 在各参与子服的 `plugins/ArcartX-Suite/data/tab/config.yml` 中设置 `settings.proxy-roster: true`，执行 `/axs reload tab`。
2. 在 Suite Velocity 插件的 `proxy-config.yml` 中加入以下设置，保存后重启代理。

```yaml
tab-list:
  enabled: true
  max-remote-entries: 80
```

`max-remote-entries` 限制远端名单人数，可设为 1～80，默认 80。名单只显示已通过进服验证且可见的远端玩家。跨服隐身要求各子服启用 Paper 的 Velocity modern forwarding，以及 Suite Essentials 和 Tab。

在启用跨服名单的子服，`/vanish` 经代理确认后生效。请等隐身状态更新再切服，在切服完成后再开启隐身。

## 检查显示与隐身

用两个账号分别进入不同子服，按 Tab 核对名单，再让其中一人隐身并切服，确认另一人的名单仍隐藏该玩家。
