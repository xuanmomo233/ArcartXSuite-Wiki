| 项目 | 说明 |
| --- | --- |
| 模块 ID | `onlinerewards` |
| 主配置 | `plugins/ArcartX-Suite/data/onlinerewards/config.yml` |
| 主要调整内容 | sign-in.yml 签到奖励、rewards.yml 时长奖励 |
| 重载 | `/axs reload onlinerewards` |

## 开始前

安装 `PlaceholderAPI`，用 `/axs status` 确认模块已加载。

## 第一次使用

按[短阶段奖励示例](/docs/onlinerewards/time-rewards#从一个短阶段开始测试)配置一条在线两分钟的物品奖励。用当天尚未达到该阶段的玩家执行 `/onlinerewards open`，查看进度并等到阈值。

## 检查是否配置成功

达到阈值后，应自动收到两颗苹果。未收到时先用 `/onlinerewards status` 核对当天累计时长。签到可另用 `/onlinerewards signin` 验证。

### 邮件预设奖励

按[阶段推进机制](/docs/onlinerewards/time-rewards#阶段推进机制)设置预设及存储，再用 `/mail` 核对收件与领取。

## 可以配置的功能

| 特性 | 说明 |
|---|---|
| 四维在线时长统计 | 今日 / 本周 / 本月 / 总在线分钟数，每分钟 tick 累计 |
| 在线阶段奖励 | 按当日累计在线分钟数分阶段触发，支持命令、邮件预设、物品奖励 |
| 每日签到 | 每日签到领取基础奖励，支持进服提醒 |
| 连续签到里程碑 | 连续签到天数"恰好等于"指定天数时触发额外奖励 |
| 累计签到里程碑 | 累计签到天数"恰好等于"指定天数时触发额外奖励 |
| 每月指定日期奖励 | 每月特定日期签到触发额外奖励 |
| 节日签到奖励 | 指定月日签到触发节日奖励 |
| 补签卡 | 消耗补签卡补签本月今天之前未签到的日期 |
| 权限组加成 | 拥有指定权限的玩家签到时额外发放一组奖励 |
