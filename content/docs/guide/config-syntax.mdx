## 示例的配置位置

点号表示字段层级。例如 `scanner.keybind.name` 展开如下。同级使用相同数量的空格缩进。

```yaml
scanner:
  keybind:
    name: AXS_PICKUP_PICK
```

将局部片段合并到指定文件的原有小节。同名小节只保留一份，整份文件示例以对应模块的说明为准。

## 看懂字段类型

| 类型 | 写法示例 |
| --- | --- |
| 开关 | `enabled: true` 或 `enabled: false` |
| 数值 | `amount: 8`、`multiplier: 1.1` |
| 文本 | `name: "欢迎礼包"` |

### 列表与映射不要混用

列表项以 `-` 开头，例如 `material-ids: [fishing_rod, stick]`。映射为键值对，例如 `nbt-values: {rod_id: jade_rod}`。

## 引号、注释和空值

含冒号或井号的文本用引号包住。引号外用于注释的 `#` 后内容会被忽略。`[]` 是空列表，`{}` 是空映射，`""` 是空字符串。

## ID、显示名称和占位符不同

引用预设或商品时填写定义 ID。命令格式中的 `<玩家名>` 换成实际玩家名。字段支持变量时，保留 `{player}` 或 `%axsfishing_level%` 的外围符号。

## 单位与大小写必须按字段

按字段要求填写秒、毫秒、tick 或字符串时长。保留键名的大小写与连字符，例如 `default-key` 和 `defaultKey` 分别用于不同配置。

## 正则与标签从哪里开始

[物品匹配与消耗](/docs/guide/item-matching)解释正则、标签键名和具体值的写法。

## 修改后怎样检查

使用 UTF-8 保存，按模块说明重载。查看[配置日志](/docs/guide/config-management#配置读取与诊断)，再用预期成功和预期失败的操作各验证一次。
