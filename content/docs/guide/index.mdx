## 版本区别

| 能力 | 免费云端版 | 付费客户水印版 |
| --- | --- | --- |
| 模块获取 | 29 个正式模块可在云端免费装备 | 使用客户安装包提供的本体与水印模块，每台游戏服的模块分别授权 |
| 游戏服连接 | 单台游戏服内使用 | 可配置[跨服 Redis 与 ArcartXSuite Proxy](/docs/guide/cross-server-setup)，使用 Suite 代理转发与认证 |
| 模块功能 | 本服名单、传送、Market 商店与拍卖、共享仓库和 EventPacket 规则 | 可配置跨服名单、跨服传送及多服共享业务数据 |
| 配置修复 | 用 `/axs config apply <模块ID>` 应用单个模块的修复建议 | 当前游戏服有有效客户模块席位时，可用 `/axs config apply all` 批量应用 |
| EventPacket 副本通关邮件 | 使用 SQLite 处理本服副本结果 | EventPacket 持有有效客户席位时，可用共享 MySQL [跨服编排副本通关邮件](/docs/eventpacket/actions#副本通关邮件) |

从群组服调整为单服部署时，保留原数据库中的已成交订单、店铺和仓库数据。
