## 免费装备云端模块

Suite 的 28 个正式云端模块均可免费装备。每台游戏服使用自己的服务器码，服主可分别选择要启用的模块。

1. 完成[本体安装和云端账号绑定](/docs/guide/first-run#云端账号与服务器绑定)。
2. 在云端后台的「装备模块」选择目标服务器并装备需要的模块。在游戏服的 `config.yml` 中开启对应的 `modules.<模块ID>.enabled`。
3. 执行 `/axs sync` 同步装备，再执行 `/axs status` 检查模块是否启动。模块的依赖插件和配置仍按各模块文档准备。

免费云端版支持 Redis 和代理的[基础跨服通信](/docs/guide/cross-server-setup)，也可使用 `/axs config apply <模块ID>` 应用单个模块的配置修复建议。

## 安装客户水印包

客户水印包包含对应操作系统的 Suite 本体和交付模块。模块以 `.axb` 文件放在 `plugins/ArcartX-Suite/modules/`，运行时向云端验证席位并获取解密密钥。

1. 在游戏服停止时，将安装包的 `plugins/` 目录复制到服务器根目录。升级时使用同一批次的本体和模块文件。
2. 在每台游戏服上使用客户账号完成云端绑定，确认各自的 `cloud.server-code`，将对应的服务器码交给分发方。
3. 分发方在云端管理后台的「授权管理 → 登记客户水印包」导入该批次的登记文件，按包内模块和服务器码发放席位。同一客户在两台后端使用同一个模块时，两台后端各需一个席位。
4. 席位生效后执行 `/axs sync`，再用 `/axs status` 检查相应模块。席位到期或撤销后，该安装失去对应水印模块的运行授权。

## 客户版功能

| 功能 | 使用条件 |
| --- | --- |
| [批量应用配置修复](/docs/guide/commands#配置检查) | 客户水印版本体在当前服务器上至少有一个有效的客户模块席位。命令为 `/axs config apply all`。 |
| [副本通关邮件的跨服编排](/docs/eventpacket/actions#副本通关邮件) | 客户水印版 EventPacket 持有当前服务器的有效席位，且 EventPacket、Abyss 和 Mail 使用同一套宿主共享 MySQL。 |
