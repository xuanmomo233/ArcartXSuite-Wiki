游戏内命令以 `/` 开头，控制台通常省略。`<参数>` 为必填，`[参数]` 为可选，输入时省略括号。

## 日常管理

| 命令 | 用途 |
| --- | --- |
| `/axs help` | 查看帮助 |
| `/axs status` | 查看本体和模块状态 |
| `/axs reload <模块ID>` | 重载已加载的模块，例如 `/axs reload announcer` |
| `/axs reload all` | 读取可重载的本体配置，按本地开关启停模块并重载其余已启用模块。提示需重启的设置见[生效方式](/docs/guide/first-run#保存后怎样生效) |
| `/axs sync` | 同步当前服务器的模块装备，按本地开关和前置条件加载新装备的模块，卸下已取消装备的模块 |
| `/axs update <模块ID或all>` | 更新已加载的云端模块，操作前先阅读发行说明 |

可在控制台运行本页的管理命令，游戏内需要 `arcartxsuite.admin`，该权限默认授予 OP。重载、同步或更新时，等控制台显示操作结果，再执行 `axs status` 核对模块状态。普通玩家的功能权限见各模块的「命令与权限」页。

## 配置检查

| 命令 | 用途 |
| --- | --- |
| `/axs config diagnose [模块ID或all]` | 检查已注册的配置，省略参数时检查全部 |
| `/axs config status` | 查看当前会话的诊断结果概况 |
| `/axs config preview <模块ID或all>` | 查看诊断发现的问题和建议值 |
| `/axs config apply <模块ID>` | 将该模块已确认的修复建议写入配置 |

在控制台先执行 `axs config diagnose`，再执行 `axs config preview all` 核对报告。确有建议需要应用时，将 `<模块ID>` 换成报告中的 ID，应用后按模块文档重载并重新诊断。

## 查找某个功能的命令

进入[模块目录](/docs)，选择模块后打开「命令与权限」。玩家入口例如 `/menu open example`、`/warehouse open` 和 `/onlinerewards open`，以模块实际配置为准。
