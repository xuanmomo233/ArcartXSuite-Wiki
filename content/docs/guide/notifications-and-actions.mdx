按接收范围选择公告、字幕、聊天消息或卡片。使用信号联动时，启用接收模块并配置对应规则。

## 各类通知怎样选择

| 类型 | 提供或处理模块 | 适用场景 |
| --- | --- | --- |
| 公告轮播、立即或排队广播 | Announcer | 本服或按配置跨服发送公告 |
| 字幕组 | Announcer | 对指定玩家播放已配置字幕序列 |
| 聊天卡片 | Chat 或明确支持该卡片的功能 | 显示任务、物品或通知的结构化内容 |
| QQ 群消息 | QQBot | 向指定群或已配置群发送消息 |
| 自定义信号与动作 | EventPacket | 收到指定信号后执行任务、字幕、消息或命令 |
| 地图与任务导航 | Map、QuestGPS | 打开、推送或追踪实际存在的目标 |

没有启用接收方模块或没有对应 ID 时，可能没有效果。应先独立验证一条字幕、卡片、预设或任务，再组合联动。

## 各模块的联动入口

| 调用场景 | 实际用法与边界 |
| --- | --- |
| AfkReward | 进入、离开、开始、结束和发奖可发送信号；`manual.subtitle-on-reward`、`manual.subtitle-on-end` 指定字幕组，邮件结束配置另见邮件派发 |
| EventPacket | 信号规则可执行任务、字幕、消息和命令。首次准入等业务事件可配置持久邮件。 |
| Menu | 按钮 `SIGNAL` 动作可发送信号，其他按钮动作有自己的配置格式；不是直接粘贴 EventPacket 的 `actions` 列表 |
| Abyss | 副本脚本有公告、字幕、聊天卡片、QQ 通知、战斗效果、任务等动作，使用副本动作语法与目标选择器 |
| Mail | 收件提示可使用配置的通知卡片；邮件存在和通知显示应分别验证，卡片未显示不代表没有收到邮件 |
| Fishing | 存在称号和邮件等里程碑联动，例如首次传奇捕获邮件；不是所有里程碑都能通过任意同名字段改写 |

为 AfkReward 区域发奖配置联动时，使用信号 `afk_reward`。

## 用信号播放字幕

在 Announcer 中配置字幕组 `welcome_demo`，再将以下规则加入 EventPacket 主配置的 `rules` 段。

```yaml
rules:
  welcome-notice:
    trigger: signal
    signal: welcome_demo
    actions:
      - type: subtitle
        group: welcome_demo
```

重载 EventPacket，执行 `/axs eventpacket fire welcome_demo WikiTester`。把玩家名换成在线测试账号，字幕播放后即可在菜单绑定同名信号。 [动作配置](/docs/eventpacket/actions)

## 定时与声音等其他公共需求

周期性控制台命令使用 EventPacket 的 `schedule` 规则配置。 [定时命令](/docs/eventpacket/services)

在[过场演出](/docs/conversation/cinematic)中，`sound` 使用原版音效，`arcartx_sound` 使用 ArcartX 资源。菜单、地图和副本的声音按对应页面配置。
